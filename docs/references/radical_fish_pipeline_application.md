# Radical Fish 방식과 본 프로젝트 모딩 파이프라인의 대응

조사일2026-09-20. 제작자 근거는 [캐릭터 조사](radical_fish_animation_research.md)와 [환경 조사](radical_fish_render_research.md)에 둔다. 아래 수식은 **공개 설명을 Unity용 계약으로 정리한 제안**이며 제작사의 비공개 구현식을 복원한 것이 아니다. 이번에는 캐릭터/Unity 구현을 하지 않았다.

## 사용자 질문에 대한 결정

Alabaster Dawn에 대해서는 픽셀 파츠를3D본에 부착한다는 사용자 이해가 맞다. 완성 전신의 모든 방향×동작×시간 프레임을 개별 저작하는 방식과 다르다. CrossCode의 일반 캐릭터는 대부분 수작업 애니메이션이라고 제작진이 구분했고, 복합 보스에는 파츠 조립이 있었다. 제작자가 밝힌 최대16방향은 당시 시스템 능력이며 모든 파츠가16장의 그림을 갖는다는 증거는 아니다.

본 프로젝트의 유력한 연구 후보는 **canonical 3D rig + 방향별 rigid pixel parts + 카메라 상대각 그림 선택 + 공통 렌더/캐시**다. 한 장을 휘어 만드는2D메시 변형과 입력 계약이 다르다. 현재 캐릭터를 즉시 이것으로 바꾸는 승인이나 구현 완료로 기록하지 않는다.

## 단계별 계산과 자료의 소유권

1. **원본 재료:** 파츠ID,방향별 RGBA atlas,각 그림의 pivot와끝점 landmark,기준부위길이(m),카메라 규격. 픽셀 원점은좌상단/중심(i+.5,j+.5),UV변환시v축방향을명시한다. 그림1장의 보이지 않는 면은 추가자료 없이는 결정할 수 없다.
2. **골격:** root→parent→bone의 local transform을 합성한다. `G_b(t)=G_parent(t)L_b(t)`; 모든L은같은canonical bind/axis/unit에서정의한다. 그림의 anchor는 `p_b(t)=G_b(t)a_b`. 애니메이션곡선은 파츠그림과분리해재사용한다.
3. **그림 선택:** bone-local 관찰방향 `v_b=normalize(R_b^-1(c-p_b))`를 계산하고, 미리 저작한 방향표의 sample과가장 가까운 것을선택한다. 지면yaw만사용하는 단순후보는 `k=round(Dθ/2π) mod D`. 실제 제작사는 세부방향표/임계값을공개하지않았으므로 이식을위한선택식이지확인사실이아니다. 경계왕복시 hysteresis는추가설계항목이다.
4. **위치·회전·길이:** 공통카메라투영 `s=viewport(PV p)`로 관절시작/끝을투영한다. 화면방향 `φ=atan2(Δs_y,Δs_x)`,표시길이`ℓ=||Δs||`에서 billboard의회전/길이를결정할수있다. 관절anchor가그림pivot과맞아야하며 화면맞춤임의offset으로대신하지않는다. `ℓ→0`인정면단축은그림/자세전환 또는최소길이계약이필요하다.
5. **합성:** 깊이,alpha cutout,부위겹침과조명은별도계약이다. 파츠RGBA만으로 앞뒤겹침/그림자부피가저절로맞지않는다. 한캐릭터의world transform은공통이고부위별PPU를눈대중으로조정하지않는다.
6. **출력:** runtime조립또는정해진D방향/F시점캐시를선택할수있다. 캐시는원본rig/atlas를대체하지않으며mod변경시관련키만다시굽는다. 정적책상은bone없이geometry/UV/material이canonical원본이다.

## 제작량과 한계

전신프레임저작량을거칠게 `캐릭터수×동작수×방향수×프레임수`라놓으면,파츠방식의그림입력은 `Σ_b(파츠b의방향수×자세변형수)`와공유bone곡선으로분리된다. 실제절감배수는그림수/예외/제작시간없이계산할수없다. 의상·체형이달라지면pivot/기준길이/겹침및특수포즈프레임이추가될수있다.

이런분리는모딩에적합하다. 그러나동일본을공유한다고모든스킨이같은품질이되거나수작업16프레임과픽셀단위동일해지는것은아니다. 제작자도일부각도누락·부정확성,확대/저속에서보이는문제와맞춤프레임보완을명시했다. 아트입력이부족한상황과계산오류를분리해야한다.

## 최소 연구 실험 제안 — 미실행

추후승인시한캐릭터의걷기한동작,공통rig/소수정면계열파츠,고정카메라로시작한다. 계산중간의관절/pivot연속성과각도선택/가림계약만최종기술검사하고실제연속동작은사용자에게판정받는다. 정면그림하나에서후면자료를발명하거나,캐릭터전체를셀수없이임의조정하는방식을재사용하지않는다.
