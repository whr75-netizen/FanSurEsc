Sprite Pipeline — 처음 한 번 연결하기

1. ChatGPT에 로그인된 Chrome에서 chrome://extensions 를 엽니다.
2. 오른쪽 위 '개발자 모드'를 켭니다.
3. '압축해제된 확장 프로그램을 로드합니다'를 눌러 다음 폴더를 선택합니다.

C:\Users\JG\Documents\work\Fantasy Survival Escape Game\Tools\SpritePipeline\browser-extension

4. Sprite Pipeline 화면으로 돌아와 GPT 이미지 프롬프트, Grok 동작 프롬프트,
   최종 프레임 수를 입력하고 실행합니다.

구간별 버튼만 쓰면 선택한 구간에서 끝납니다. 이미지·영상·PNG 프레임을
파일로 입력하거나 최근 중간 결과를 재사용할 수 있습니다.
전체 루틴 ON이면 구간 버튼 이후 남은 단계를 이어가며 Inbox의 새 파일도 감시합니다.
감시 폴더는 화면에 표시되는 Inbox/images, Inbox/videos, Inbox/frames 입니다.
OFF 또는 중단을 누르면 현재 구간 저장 후 멈춥니다.

전용 확장은 chatgpt.com과 로컬 실행기(127.0.0.1)에만 접근합니다.
실행기가 새 작업 링크로 연 ChatGPT 탭에서 프롬프트를 제출하고,
생성 이미지 파일을 로컬로 전달합니다. 그 탭은 이미지 저장까지 열어 두세요.
ChatGPT 로그인 확인 화면이 나오면 직접 로그인해야 합니다.
다른 Chrome 프로필에서 열리면 해당 프로필의 ChatGPT 로그인과 확장 설치를 확인하세요.

이후 실행: 같은 상위 폴더의 Start.bat 더블클릭.
종료: 실행기 콘솔 창을 닫습니다. 진행 중 생성이 있다면 공급자 작업은 계속될 수 있습니다.
실행기 종료가 원격 생성 취소를 의미하지는 않습니다.

현재 검증 범위: 로컬 후처리, 입력 검사, 중복 실행 방지, 확장 코드 검사.
위 확인은 초기 버전 기록입니다. 최신 구간 버튼·폴더 감시 추가 뒤에는
사용자 요청에 따라 추가 검증이나 결과물 재처리를 실행하지 않았습니다.
확장 설치 후 실제 ChatGPT 새 이미지 생성 → 파일 저장 → Grok 연결은 아직 미검증입니다.
페이지 구조가 달라지거나 최종 이미지 판정이 불확실하면 작업을 멈추며 재생성하지 않습니다.

결과 폴더: 프로젝트\LocalOnly\SpritePipelineRuns\실행ID
원본 이미지·영상·출력과 단계별 기록을 실행별로 보존합니다.
