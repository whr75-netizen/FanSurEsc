PerfectPixel — 전역 균일 격자

볼록·오목거울처럼 휘는 변형을 줄이기 위한 별도 처리 경로입니다. 기존 원본 실행기·수정판·Unity 씬은 바꾸지 않습니다.

원본 자동 검출로 간격을 추정하고, 단일 전역 격자로 샘플링합니다. 자동 추정은 원래 픽셀 격자가 맞다는 증명이 아니며, 작은 특징이 사라질 수 있습니다.

입력: RGB/RGBA uint8, 단일 이미지, 최대 4 MP / 20 MiB. 파일 바이트를 그대로 전송합니다. 확대는 CSS 미리보기에만 적용하며 다운로드 PNG는 확대하지 않습니다.

이미지를 선택해 주세요.
