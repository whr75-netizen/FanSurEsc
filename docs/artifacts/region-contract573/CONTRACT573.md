# 573 저장 입력 계약 검증 명세

제품 미연결. 572의 면적/선택 마스크와 열린끝136건은 변경하지 않는다. source의 분기 정보와 최종 셀 소유권의 의미를 먼저 구분한다.

|입력 유형|출력 의미|검증/충돌 처리|
|---|---|---|
|cap/열린 입구|기존572의 FILL/KEEP 및 source 입구→선택변|기존136건 결과 보존. 원입구 축/좌표 고정 제약을 다시 넣지 않음|
|split/merge|연속 원형의 인접 가지·공통 event→유지된 incident 부분과 실제 선택 접속|원본의 양의 폭 연결만 자동으로 같은 junction으로 묶음. 사라진 가지는 FILL 근거가 필요하며, 끊긴 유지 가지를 임의 근접으로 연결하지 않음|
|닫힌 원영역|source 안의 닫힌 음의 성분→하나의 닫힌 선택영역 KEEP 또는 FILL|새 외부 연결/무근거 분할은 통과가 아님. 실제 source 위상와 명시적 디자인 변경을 구분|
|양 축의 중복 표현|같은 원형을 x/y로 기술한 chart incidence|원형 조각의 실제 겹침·연결로 별칭을 합침. 축 우선순위나 최대면적 투표로 의미 소유자를 고르지 않음|
|최종 머리 셀|Hair 영역 소유자 하나|색·UV·깊이 표면 공급은 별도 미검증 계약으로 유지|
|최종 빈 셀|셀 안의 실제 연속 음의 조각에서 한 소유자|한 셀 내 source 연결 조각은 합칠 수 있음. 머리 띠로 분리된 조각이 여러 개면 현재 bool 선택만으로 어느 형상을 생략했는지 증명하지 못하므로 미해결로 남김|

소유권은 출력 배경 connected-component 번호를 붙이는 것만으로 통과시키지 않는다. 열린 틈들이 바깥에서 연결돼 있어도, 같은 셀 안의 양의 가닥을 지우는 국소 병합은 별도 형상 결정이다. 한 셀을 음으로 선택했다는 사실만으로 그 병합이 요구에 맞는다고 소급 선언하지 않는다.

진단은 572의 **디자인 폐영역**에서 음의 조각을 추출한다. 원래 cap FILL 전의 형상을 그대로 사용하지 않는다. 기존 CurveArea511의 동일 sweep에 관측만 추가한 독립 진단에서 저장 면적 bit가 일치하는지 먼저 확인한다. 새 선택기·패널티·포즈·렌더를 만들지 않는다.

모든 유형과 소유권이 통과하기 전 제품 경로에 연결하지 않는다. 형상 선택이 부족하면 첫 명확한 반례와 두 대안의 대가를 제시하고 추가 패치를 중단한다.
