아래는 이전 `2d2dae7`의 연결 복구 이력입니다. 그 수정만으로 넓은 그라데이션의 공통 단계가 해결된 것은 아닙니다. 현재 Chibi 실행 설정은 `region_tones.mode=continuous`로 전환했습니다. 출력 격자/SLIC 조각 수와 무관한 색 연속 영역 + 원본 대표색 오차 기반 가변 단계입니다. 기존 결과/legacy 참조 팔레트 모드는 보존했습니다. 현재 결과·수학·재실행·한계는 `CONTINUOUS_GRADIENT_REVIEW_20260908.txt`를 보십시오. Unity 실시간 렌더러 이식은 하지 않았습니다.

## 사용자 확정과 실제 원인

- 현재 테스트 크기는 96×192. 기존 밝은 native PBR 촬영 원본은 그대로 사용합니다.
- 고슴도치의 `tones=3`, `min_retained_tone_delta_l=.06`은 영역별 명암 처리입니다. 캐릭터에 적용했던 `colors=64`, `iterations=3`은 전체 색 군집화입니다. iterations는 명암 단계 수가 아닙니다.
- 처음 캐릭터는 연결 영역 4348개가 만들어져 후속 4096 제한에서 중단됐습니다. AI가 요구된 명암 처리를 보존하지 않고 다른 색 처리 경로로 변경했습니다. 이는 자동 fallback 버그가 아니라 **실패 후 요구 기능을 바꿔서 결과를 만든 작업 판단 오류**였습니다.
- 모듈상 두 실험 경로가 분리되어 있었고, 개별 촬영 실행기가 색 처리·샘플링 순서를 약 200줄로 다시 조립했습니다. 단계별 명암 사용 여부를 보장하는 공통 계약 검사가 없었습니다.
- 조사한 실행 경로에는 고슴도치/캐릭터 이름에 따른 분기나 부위 좌표 예외가 없었습니다. 같은 알고리즘도 입력·설정·참조색이 다르면 결과는 달라집니다. 요구된 처리 단계를 누락하는 것은 다른 문제입니다.

## 수정한 단일 처리 경로

`capture run_review.py → trigger_cli → normalize_triggered(region_tones) → prepare_region_tones → segment_regions + color_regions → raw-source cell sampling`

- 기존 고슴도치의 `get_boundary_pixel`도 동일한 `prepare_region_tones`를 호출합니다. 고슴도치와 캐릭터의 명암 수학 코드를 복제하지 않습니다.
- `region_colors`와 `region_tones`를 동시 사용하면 거부합니다. 명시적 reference와 `source_regions` 샘플링을 요구하고, 알고리즘 실패는 호출자에게 전파합니다.
- 캐릭터는 원본 자체를 reference로 명시합니다. 고슴도치의 Canva 참조 이미지·색감이나 anime의 수동 선택 좌표는 복사하지 않습니다.
- 명암/팔레트는 색만 변경합니다. 원본의 셀 내 색 연결 영역으로 선택하는 좌표 계약은 유지합니다.
- `region_tones`와 선 정규화 동시 사용은 아직 검증되지 않아 명시적으로 거부합니다. 검증 없는 선 채움이나 다른 색 처리로 대체하지 않습니다.
- SLIC 시작점 4096개와 실제 연결 영역 수를 분리했습니다. 분할이 이미 허용한 연결 영역 용량 65536을 후속 단계도 공유합니다. 실제 tone-node×candidate 비용 배열의 64MiB 예산은 계산 전에 검사합니다. 전체 메모리/최악 시간 보장이 아닙니다.
- 영역을 지우거나 강제 병합·숨은 resize·재시도로 한도를 우회하지 않습니다. 기존 merge heap의 최악 비선형 비용은 별개의 미해결 성능 한계입니다.
- 수천 개 영역의 상세 진단은 JSON에 보존하고 stdout에는 요약만 냅니다. 96×192 1회 처리에서 기존 상세 출력이 약 28만 토큰 상당이었던 불필요한 중복도 제거했습니다.

## 그라데이션 길이·범위

기존 명암 함수는 영역의 실제 Oklab 명도 최소~최대 범위로 1~3톤 예산을 정하고 대표 밝기 구간으로 나눕니다. 길이 자체를 단계 수로 쓰지 않습니다. 같은 밝기 변화가 공간적으로 8배 길어져도 톤이 늘거나 모양의 다른 규칙이 생기지 않아야 합니다.

그 길이 불변성을 합성 그라데이션으로 검증했습니다. 현재 수학 자체를 다른 공식으로 임의 교체하지 않았습니다. `.06`은 약한 명암을 반드시 다른 색으로 유지하라는 제약을 완화하는 값이며 강제 병합·모든 이미지 최적값은 아닙니다. 분할 영역은 의미적 피부/머리 재질과 동일하지 않습니다.
