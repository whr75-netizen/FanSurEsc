# 569 얼굴 쪽 앞머리의 양의 끝 출몰 — 기존 실제 영상 역추적

**실제 저장 Walk71→72→73에서 앞머리 끝 한 셀의 머리→빈칸→머리를 확인했다. 최초 관측 손실은 합성/눈 가림이 아닌 선택 그룹 생성 단계다.** 새 메시 전처리·렌더 패치·Unity 촬영은 하지 않았다. 기준564와 후보566 모두 같은 관측이며567 전체 검증을 재시작하지 않았다.

실제 연산은 다음 순서다.

1. `HeadCurve511.Areas511`이 변형된 기하 anchor를 투영한3폐곡선으로 양의 면적과 음의 가지를 계산한다.
2. `NegativeRegion563.Feature.OwnedCells()`가 `cellArea>.5`인 셀을 목록으로 만든다. 연속 가지 자체는 계속 존재한다.
3. `NegativeRegion563.Groups()`는 소유셀의8이웃 성분이2개 이상이면 equality 그룹을 낸다. 따라서71/73은 singleton이라 제약 없음,72만 두 셀 그룹이다.
4. `HeadRegion502.SelectRegions543`의 `flow.Link(group[0],group[j],100000)`가 **양의 머리 상태도 두 셀에서 같게** 강제한다. 음의 틈의 그룹이 양의 끝 선택에 직접 영향을 준다.
5. 선택 false인72는 `HeadRegion502.Prepare`의 `if(Hair[...])` 패킷 생성에 진입하지 않는다. 실제 저장 패킷도0, 최종meta도0이다. 후단 눈/얼굴 깊이 비교에서 처음 사라진 것이 아니다.

`ΔE=E(유지)−E(생략)=1−2A+Σw(1−2n)`이며 축 이웃 w=.14×.58578644, 대각선 w=.14×.29289322다.72의 대상 한 셀은 이웃항−.246030305, 단독 ΔE=−.216874037로 **유지를 선호**한다. 하지만 그룹의 다른 셀(232,46)은 머리 면적이 .024005927뿐이다. 두 셀을 같이 유지하면 단항합 .981144413, 그룹 외부 이웃항−.328040406, ΔE=+.653104007로 **둘 다 생략을 선호**한다. 내부 공유 변은 두 상태에서 차이가 없어 계산에서 제외했다. 실제 equality 목록은 bounds-relative `[522,555]`다. 숫자는 고정된 실제 이웃에 대한 조건부 에너지 비교이며 별도 새 전역 최적해를 계산한 것은 아니다.

71은 sm1/primitive714에서 UV(.189415753,.588294864), depth13.7254505의 원표면 패킷이 있고73은 sm1/primitive716, UV(.190886363,.573913753), depth13.7244282다.72는 마스크가 먼저 꺼져 패킷이 없다. 567에 해당 셀의 원본GPU centre/native·눈 중간 버퍼는 보존되지 않아 **72의 원래 모든 표면 깊이/가시성을 새로 조회했다고 주장하지 않는다**. source anchor0:24~28의 원삼각형 연결은 `TRACE569.json`에 보존했다. 하나의 폐곡선에는 여러 헤어 submesh의 anchor가 들어가므로 이 곡선을 단일 원본 가닥 경계와 동일시하지 않는다.

## 기하인가 알파 카드인가

원VRM의 `Hair001 (merged)`는4primitive다. 네 재질 모두 `MASK`/cutoff.5/doubleSided지만, **원 baseColor 텍스처 네 장의 알파가 전 픽셀255**이고 alpha factor1, UV scale1/offset0이다(각512×1024, cutoff 미만0). 이 입력에서는 텍스처의 투명 절단이 가닥 윤곽을 만드는 근거가 없다. alpha-card라는 재질 이름만으로 설명하면 부정확하다. 얇은 판형 기하인지 입체 가닥인지의 전체 단면 분류는 하지 않았으며, 이 사례의 원래 머리 실루엣은 실제 기하와 투영 곡선에 달려 있다. ## 범위화와 전처리의 역할

- **현재 범위화:**511은 이미 렌더 전용3폐곡선/94anchor의 자동 전처리 입력을 사용한다.566은 음의 틈 가지의 존재/ID를 중심 셀 수와 분리했다. 그러나 최종 equality의 소유셀 목록은 여전히>.5로 바뀌어 이번 양의 끝에 영향을 준다. 양/음 영역의 ID 보존과 선택 제약의 시간 품질은 별개다.
- **투영 연속 영역에서 해결 가능한 범위:**이번 첫 손실은 원본 좌표 반올림이나 알파 컷아웃 없이도 설명된다. 원곡선 진행·양의 끝과 맞은편 음의 입구를 함께 반영하는 선택 계약이 필요하다. 단순 두 셀 강제결합을 제거하면 예전16/51 틈 반례에 영향을 주므로 해당 실패 근거 없이 새 조건/시간필터를 붙이지 않는다.
- **렌더 전용 3D 덩어리 전처리 후보:**정상 주요 가닥과 의도한 끝을 유지하며 잔가닥/미세 틈을 통합할 수 있다. 원본을 보존한 파생 형상이어야 하고, 스킨/UV/표면 소유권을 유지해야 한다. 정점 좌표를 반올림하거나 원본을 파괴적으로 자르는 방식은 아니다. 지금 알파가 전부 불투명이므로 텍스처 알파만 정리하는 방법은 이 입력의 기하 끝을 바꾸지 못한다.
- **해상도:**폭/면적은 실제 `Project` 후 논리픽셀 단위로 평가해야 한다. 같은3D 폭도 거리/시선/회전에 따라 달라진다. 고정 월드 폭을1px라고 놓을 수 없고 무엇을 통합/생략할지는 디자인 정책이다. 모든1px 끝을 삭제하거나 원세부 전부 보존하는 정책을 추가하지 않았다.

3D 전처리가 필수라는 결론은 아니다. 새로운 표현을 채택하려면 실제 걷기에서 얼굴 쪽 양의 끝과 정상 음의 틈을 함께 유지하고, 회전 시의 보이는 경계·머리 변형·눈/얼굴/앞가림을 검사해야 한다. **567의 yaw260 공통511 투영 winding 실패**도 별도 선행 문제라 현재3D anchor 링을 모든 방향의 가시 실루엣이라고 사용할 수 없다. 이번은 첫 원인과 전처리 대안의 적용 범위를 좁힌 검토이며 제품 수정/전체 해결 판정이 아니다.
