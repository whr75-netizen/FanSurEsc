# B35 물리 배치 결정

2026-09-27. 실제 씬 변경이 아닌 제작 입력과 정적 계산입니다. 부모 작업이 확인한 시점/가구 정면 충돌 때문에 판매 선반은 오른쪽 벽, 냉장장은 뒤쪽 왼편으로 옮깁니다. 진열섬은 (1.8,-2.1)의 높이 .65m 몸체와 별도 상판 상품 두 개로 구성합니다. 나머지 기본 5개 시설 중 계산대·뒤 선반·창고 선반의 원래 좌표는 유지합니다. 준비대·청소장은 별도 실내 계획의 좌표를 재사용합니다.

단일 원본은 `placement.json`입니다. 위치는 건물 local X/Y/Z의 **바닥 또는 지지면 중심점**이고 `collider_size`는 X폭/Y높이/Z깊이입니다. Collider의 중심은 base Y에 높이 절반을 더해야 합니다. 원본 그림의 크기나 투영 외곽을 Collider 크기로 대신하지 않습니다.

20개는 실제 별도 인스턴스 수입니다. 기본 가구 8개, 상판 소품 3개, 화분 2개, 식품 보관 통 2개, 상자 5개입니다. 이미 그림에 있는 선반 상품은 추가 인스턴스로 세지 않습니다. 5개 상자는 왼쪽 외곽의 낮은 보충 물품과 창고 뒤쪽의 실제 상하 스택으로 분리합니다. 통은 쓰레기통이 아니라 같은 식품 보관 역할의 묶음입니다.

`Tools/Building35/compute_placement.py`가 기존 B32 shell의 해시를 확인하고 직육면체 내부 충돌, 지지면 포함/높이, 기존 주통로, Player 반지름을 더한 0.1m 격자의 4방향 경로를 계산합니다. 원본 계획을 자동 이동·수정하지 않습니다. `layout-route-report.json`과 B33와 같은 routes/points 형식의 `observation-input.json`은 파생 산출물이며 Play Mode 통과 증거가 아닙니다. 최종 실제 이동은 부모 Unity writer가 수행합니다.
