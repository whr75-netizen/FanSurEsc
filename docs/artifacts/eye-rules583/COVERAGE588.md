## 하나의 실행 후보와 입력 계약

실행 파일은 `experiment588/coverage588.py`, 검사는 `experiment588/test588.py`입니다. NumPy는 기존 float32 반례 입력을 재현하는 검사에만 쓰며 커널은 Python 표준 라이브러리만 사용합니다. 기존 `HeadArea505/508`의 `Clip`/`Subtract`와 같은 반평면 분할 구조를 재사용합니다. 과거 전체 메시 `Union → Length` 엔진을 실행하거나 새로운 렌더러를 만들지 않습니다.

입력은 논리 픽셀 좌표의 닫힌 볼록 투영 조각, affine 깊이 z와 rest 좌표 u/v, 원본 조각 ID·레이어·소유자·앞면 여부·draw 순서입니다. **알파를 통과하는 연속 도메인이 먼저 증명되어 있어야 합니다.** 한 UV의 알파를 보고 전체 조각을 불투명이라고 가정하지 않습니다. 가변 불투명도는 그 조각 전체를 포함하는 하한과 상한으로 받습니다. 알 수 없는 알파 도메인, 비-affine 투영, 모호한 깊이 동률 등은 0이 아닌 미확정입니다.

`Kernel.nearest`는 같은 레이어의 모든 조각에서 먼저 최근접 표면을 결정합니다. 이후 owner/front/눈 영역을 검사하므로 앞 표면이 부적합하다고 뒤 표면의 면적을 빌리지 않습니다. 서로 겹치는 삼각형은 두 번 더하지 않습니다. 깊이가 변하는 겹침은 같은 화면 시선의 affine 깊이 차이를 0에서 분할합니다. 같은 깊이에서는 기존 LEqual draw 순서를 사용합니다.

`Kernel.visible`는 다른 레이어를 같은 시선에서 분할합니다. 앞쪽 몸은 면적을 제거하고, 앞쪽 헤어·눈썹은 기존 계약대로 투과율을 곱합니다. 같은 눈썹 레이어의 겹치는 삼각형을 두 번 감쇠하지 않습니다. 이 단계의 결과에는 원본 소유권을 남깁니다.

현재 작은 후보는 **하나의 source 레이어 또는 이미 정규화된 지지 도메인**만 처리합니다. 실제 Sample583의 S0/S1/S2/S3 참조 우선순위와 S0/S3 지지 fallback을 합성하는 연결부는 구현하지 않았습니다. 그런 입력을 그대로 여러 source 레이어로 주면 `REFERENCE_SUPPORT_FALLBACK_NOT_EXPRESSED`로 거부합니다. 참조 u/v와 지지 표면 깊이를 분리한 정규 도메인이 제품 연결의 선행 입력입니다.

## 중심 표본 대신 상·하한을 계산하는 식

기존 곡선 띠는 q(u)=a+b·u², down≤v−q(u)≤up입니다. 논리 픽셀 좌표에서 계산하며 면적 단위는 논리 셀²입니다. 원본의 스타일 상수 a/b/down/up/u 범위나 N=floor(A+0.5)를 바꾸지 않습니다.

u∈[l,r]에서 현의 기울기는 b(l+r), 절편은 a−b·l·r입니다. 중점 접선은 같은 기울기와 절편 a−b·((l+r)/2)²를 갖습니다. 포물선은 두 직선 사이에 있고 최대 수직 간격은 |b|(r−l)²/4입니다. 이를 affine u/v를 통해 화면의 반평면으로 옮겨 안쪽 띠와 바깥쪽 띠를 만듭니다. 원본 가시 조각을 각각 잘라 shoelace 면적을 구하면 A_lower≤A_true≤A_upper입니다. u가 상수인 화면 조각도 버리지 않고 같은 식의 정확한 선형 띠로 처리합니다.

모든 분할·교차·면적은 Fraction 유리수로 계산하므로 이 커널 안의 부동소수 반올림이나 epsilon에 의한 작은 면적 삭제가 없습니다. 이 보장은 **주어진 유리수 기하와 알파 도메인/불투명도 경계가 맞다는 조건부 보장**입니다. 입력 투영 오차나 실제 GPU의 알파 필터 도메인 오차를 자동 포함한다고 주장하지 않습니다. GPU float 이식 시의 outward rounding도 아직 구현하지 않았습니다.

검사 전에 정한 허용 면적 폭은 0.0001 셀²입니다. 0.001 판정 여유의 1/10이며 결과에 맞춘 탐색은 하지 않았습니다. 기하 상·하한 차이가 가장 큰 u 구간을 이분합니다. 최종 폭이 허용치 이내이고 두 끝의 floor(A+0.5)가 같을 때만 출력수를 확정합니다. 반대라면 `budget=null`입니다. 불투명도 불확실성을 수치 적분 오차인 것처럼 축소하지 않습니다.

## 리소스, 한계와 다음 의존성

측정은 작은 Python 오프라인 반례에 한정하며 `tracemalloc`을 켠 실행 시간과 추적 peak입니다. 최장 0.674149초, 추적 peak 최대 93,636바이트(약 91.4KiB)였습니다. 관측 최대 clip 1,588회, 깊이 비교 12회, 가시 조각 3개, 곡선 분할 133개입니다. 결과 JSON에 검사별 수치를 남겼습니다. GPU 텍스처 추가 0, 런타임 readback 0, 새 캡처 0입니다. **CPU 유리수 검사기는 실시간 제품 구현이 아닙니다.** 최악에는 깊이 비교가 O(n²)이고 분할 수와 유리수 분자 크기가 증가합니다. 조각 수/분할 수 제한은 계산 거부 경계이며 전체 메모리나 지연의 상한 보장이 아닙니다. 587의 179.4MiB 텍스처 경로는 다시 적용하지 않았습니다.

다음 제품 연결에 필요한 것은 실제 GPU 샘플 조건을 포함하는 알파 통과 도메인/불투명도 경계와, 참조 좌표·지지 깊이를 보존한 정규 가시 조각입니다. 기존 4×4 표본만으로는 이 연속 경계를 복원할 수 없습니다. 이번 단위는 그 입력을 가정한 기하·소유권 커널과 반례까지이며, 알파 도메인 생성기를 추가하거나 제품 연결을 자동 시작하지 않습니다.
