Unity implementation note
-------------------------

The Unity shader and renderer feature in this folder are an independent URP
implementation of the tutorial's low-resolution sampling plus depth/normal
edge-detection technique. No Godot scene, imported demo model, icon, texture,
or Godot shader source file is shipped in this Unity project.

Additional technique references:
- Godot advanced post-processing documentation:
  https://docs.godotengine.org/en/4.4/tutorials/shaders/advanced_postprocessing.html
- three.js pixel post-processing example by Kody King:
  https://threejs.org/examples/webgl_postprocessing_pixel.html
