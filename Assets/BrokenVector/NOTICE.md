# BrokenVector Low Poly Brick Houses

This project includes the **Low Poly Brick Houses** asset by Broken Vector.

- Source: https://marketplace.unity.com/packages/3d/props/exterior/low-poly-brick-houses-131899
- License: Unity Asset Store Standard EULA
- Project use: source models for the project-owned urban building adapter prefabs under `Assets/Prefabs/WorldGeneration/Buildings/`

The source package is kept separate from project-owned gameplay, collision, navigation, and orientation data.
