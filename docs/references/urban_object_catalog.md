## 현재 D09 — 실제 3D 소품과 건물 용도

[최신 사용자 요청] 구현은 일시 중단했습니다. 사용자는 전체 인수인계와 PixelLab 픽셀 소품·기존 무료 에셋 활용 대신 3D를 저작한 이유의 설명을 요청했습니다. 현재 D09 디자인은 **미승인**이며 이후 표현 방향과 실내 역할 분리 판단은 보류 상태입니다. 아래 표는 실제 만들어진 구현의 기록이고 최종 아트 방향의 승인이 아닙니다.

[현재] D09은 실제 물체 부품으로 만든 3D 소품 11종과 가로수 모델을 사용합니다. `Assets/Art/UrbanCoherent09/Models/`의 FBX와 `modelmetadata.json`이 모델·미터 bounds·재질·부품 recipe를 기록하며, 저작 도구는 `Tools/WorldArt/create_urban_models.py`입니다. 기본 출력과 정확한 CLI 옵션은 [도구 README](../../Tools/WorldArt/README.md)에 있습니다. D08의 완성 sprite를 cube 면에 붙이거나 숨은 면을 복원한 결과가 아닙니다.

PixelLab의 생성 범위는 아래 평면 재질이며 소품 형상은 Blender 스크립트가 별도로 만들었습니다. D09 kit의 FBX는 PixelLab 완성 픽셀 오브젝트나 외부 무료 완제품 모델을 도입한 산출물이 아닙니다.

현재 구현에는 3D 저작 뒤 픽셀 이미지로 자동 교체하는 단계가 없습니다. 물체 형상은 런타임에서도 3D mesh를 유지하고 PixelLab은 표면 재질을 제공합니다. 최신 정정에서 담당AI가 픽셀 목표를 제작 편의상3D로 대체한 잘못을 인정했습니다. 재개는 `urban_pipeline_handoff.md` N01의 픽셀 제작 계약 복구이며, 픽셀을 원하는지 다시 묻거나 현재3D유지를 전제로 확대하지 않습니다.

표면은 PixelLab 작업 `f9eb76e3-4443-4a61-a070-7db94bcee95e`의 네이티브 64×64px 원본 16장입니다. `Assets/Art/UrbanCoherent09/Surfaces/Source/`에 원본을 보존하고, `pack_square_urban_kit.py`로 2px edge padding을 둔 atlas와 해시 manifest를 만듭니다. PerfectPixel 정규화 호출은 0회이며 2m 반복·32texel/m입니다. 공통 material은 `Urban_Wood`, `Urban_MetalDark`, `Urban_MetalLight`, `Urban_Glass`, `Urban_Olive`, `Urban_Fabric`, `Urban_Ceramic`, `Urban_Brick`입니다. Wood/Brick은 반복 원본 텍스처, 나머지는 원본의 지정 위치 색을 사용합니다.

## 현재 D09와 보존 D08의 지원 경계

- D09은 바닥 중심의 실제 mesh·미터 footprint·건물/필지 frame을 공유한다. D08의 바닥 지지 수직 billboard와 별도 경로이며 기존 sprite를 입체 복원하지 않는다.
- D09 책상의 PC·키보드, 진열 선반의 상자, 작업대의 공구는 모델의 고정 부품이다. 독립적인 작은 물건의 선반/책상 지지면 배치, 벽·천장·지붕 부착, 러그, 연결형 펜스는 여전히 별도 알고리즘이 필요하다. 원본 분류표에 존재하는 것과 게임에 배치 가능한 상태는 다르다.
- 구조재 6장(인테리어 타일, 건축 타일, 거리 타일, 거리/보도 타일, 출입구 facade, 계단)과 캐릭터17장은 소품 풀에서 제외한다.
- 기존 도로용 가로수/가로등은 도로 생성기가 소유한다. D09 가로수는 새 `StreetTreeVisual.prefab`을 사용하고 기존 trunk collider를 보존한다. 실제 가로등 참조는 기존 `Assets/Prefabs/Lighting/PrototypeStreetLamp.prefab`이며 Unity 확인 결과 MeshFilter 6개는 모두 `Library/unity default resources`의 기본 도형이다. 새 무료 완제품 에셋을 다운로드한 것이 아니다. 건물 소품 목록에서 도로 설비를 중복 생성하지 않는다.
- 디자인 합격은 실제 맵 화면의 사용자 확인으로 판정한다. 적합성 표 작성이나 코드 검사 통과로 대신하지 않는다.
