## 손실 반례와 최소 결정

대각 접촉2셀은 각각 닫힌 셀 경계를 갖지만, G8은 두 중심을 하나의 열린 경로로 연결합니다. 기존 영역 분리와 픽셀 인접성은 같은 관계가 아닙니다.

벽1셀 구멍은 바깥/안쪽 경계가 같은 셀4개를 사용합니다. G4에서는 중심8개가 한 순환이지만, 이 순환만 채움 경계로 삼으면 원래 비어 있던 중앙(1.5,1.5)이 엄밀히 내부가 되어 잘못 채워집니다. 원래 영역은8셀이고 중앙은 빈 셀입니다. 단일 중심 경로로 두 폐경계의 권한을 대체할 수 없다는 정확한 반례입니다. 미세 구멍의 의도적 생략을 금지하는 규칙이 아니라, 손실 변환을 자동으로 동등 변환이라 부르면 안 된다는 검사입니다.

최소 결정은 **방향 있는 셀 모서리 폐경계·채움 영역을 권위로 유지하고, 중심 경로에는 그 경계 ID와 변/안쪽 셀 incidence를 전달하는 것**입니다. 같은 셀에 여러 경계가 대응하면 소유권도 여러 개여야 합니다. 이것은 같은 후보의 두 표현이며 후단 보정 필터가 아닙니다. 공유·퇴화 구간을 단일 선으로 몰래 합치거나 지워서는 안 됩니다.
