## Input to output contract

For each enabled existing body role, the SAME `ClothRegion524` computation projects original skinned anchors and the cached material-alpha boundary, builds closed vector regions, quantizes complete outward returns using `ClosedRegionDesign539`, computes exact curve/cell area and runs the existing spatial region selector. The masks are role-owned: a four-channel atlas gates source Probe331 and Prepare333/Resolve by the existing role mapping; per-part R masks are consumed by the unchanged packet shader. An inactive role is never clipped by another role's channel.

ClothSurface525 requests empty selected destination cells once across the active parts. Each new cell must have actual visible source-triangle support in a selected part, with that triangle's submesh, primitive, barycentric point, UV, world position and depth carried together. Quad submeshes use the matching existing source/legacy material. No arbitrary RGB donor, extra colour filter, history layer, dilation, per-frame or per-cell exception is added. Body part 3 remains the legacy diagnostic API; new tests also save each part's actual curves/areas/mask.

539 replaces arbitrary RDP partial chords by whole extrema-return omission. Both returns reach a common level, progress monotonically on the other axis, and enclose outward area <=1 logical cell squared. Disjoint source intervals are selected deterministically. Winding and proper-crossing checks protect the closed region. The area allowance is an explicit pixel-art design constant in 480x272 logical coordinates, not a physically universal resolution-derived number or reproduction of the 2016 paper. The 0.75x3-cell normal-end area is 2.25, so the eight stored normal-end cases are retained. Known43/50 and normal44 were checked together in 539 and again in actual540.
