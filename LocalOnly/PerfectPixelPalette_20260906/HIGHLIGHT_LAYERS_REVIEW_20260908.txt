작업 기록이며 전역 AI 지침이 아닙니다. 외형의 최종 평가는 사용자 확인 사항입니다.

같은 원본 384x768 → 같은 96x192 격자, 원본 샘플 좌표와 alpha를 보존합니다.

실제 아트는 한 번 처리했으며 미리보기를 보고 임의 재보정하지 않았습니다.

밝음 명암 알고리즘
기존 continuous + spatial_steps 팔레트/그림자/샘플링은 재계산 방식 변경 없이 동결합니다.
highlight_accents가 원본의 같은 domain/chroma group에서 기존 spatial_tones의
여러 규모에서 지속되는 밝은 support를 사용합니다. 기존 최상단 톤 안에서만 처리합니다.
그 위치의 원본 밝기 오차를 줄이는, 실제 원본에 존재하는 더 밝은 RGB를 하나 고릅니다.
단색 밑그림 위에 투명 overlay로 얹습니다. RGB 혼합, 그림자 변경, 새 윤곽선은 없습니다.
그룹별 최대 한 색이며 근거/밝기 여유가 없으면 추가하지 않습니다.
minimum_contrast=.025, 공간 support 판정은 명시적인 휴리스틱이지 재질 인식의 정답이 아닙니다.
원본에서 찾은 작은 강조는 고정된 출력 샘플 좌표에 걸리지 않으면 보이지 않을 수 있습니다.
특정 캐릭터 이름, 부위 이름이나 좌표를 하드코딩하지 않았습니다.

편집 파일과 저장 구조
color_layers/character_layers.aseprite : Aseprite RGBA 1프레임, Base / Highlight 그룹.
Base 아래 76개 단색 레이어, Highlight 아래 9개 단색 레이어.
이번 출력에서 637개 native 픽셀에 밝은 명암이 얹혔습니다.
Highlight 그룹을 숨기면 이전 승인본의 RGBA 픽셀 데이터가 완전히 복원됩니다.
각 레이어는 한 RGB + 이진 마스크이며, 색이 같은 여러 위치는 같은 색 레이어에 들어갑니다.
머리카락/피부/의상 같은 의미상 부위 분할이나 애니메이션용 파츠화는 아직 아닙니다.

color_layers/colors.json : 수정용 RGB 값의 원본. ID를 유지하고 rgb만 바꿀 수 있습니다.
color_layers/manifest.json : 캔버스, 쌓는 순서, 레이어 ID, 마스크 위치/크기.
color_layers/masks/*.png : 색별 잘린 흑백 마스크; 255가 해당 색의 자리입니다.
color_layers/base.png, highlight.png, composite.png : 각각의 보존/확인용 이미지.
rebuild_color_layers(directory, include_highlights=True/False)가 JSON+마스크를 RGBA로 재합성합니다.
중요: .aseprite는 저장 시점의 스냅샷입니다. JSON 변경이 열린 Aseprite 파일에 실시간 반영되지는 않습니다.
RGBA 모드이므로 Aseprite 팔레트 칸만 바꿔도 기존 cel 전체가 자동 재색칠되지는 않습니다.
Aseprite에서는 원하는 단색 레이어만 선택해 픽셀 색/영역을 편집할 수 있습니다.
JSON 경로에서는 colors.json 수정 후 재합성이 필요합니다. 두 파일을 자동 양방향 동기화하지 않습니다.

실제 검증
회귀 검사 248개 통과(CLI 색 레이어 통합 2개 포함). 기존 테스트 mock 반환과 신규 rectangle(x0,y0,x1,y1) 표기 오류는 수정했습니다.
합성 파일의 Base는 result_spatial_steps_96/pixel_native.png와 RGBA byte 단위 일치합니다.
최종 alpha, source sampling 좌표, overlay 밖 기존 픽셀 보존을 확인했습니다.
변경 픽셀은 전부 Oklab L 증가, 최종 RGB는 전부 불투명 원본에서 관측된 색입니다.
JSON+마스크 재합성은 Highlight 활성/비활성 양쪽 모두 해당 이미지와 완전 일치합니다.
설치된 Aseprite 1.3.18.3-x64로 실제 --batch --save-as를 실행했습니다.
최종 합성, --ignore-layer Highlight 각각의 PNG가 새 최종본/이전 승인본과 완전 일치합니다.
기존 PixelLab extension handle-pose.lua:58 경고가 출력됐지만 PNG 생성과 픽셀 일치는 확인됐습니다.
이 경고의 수정, Unity 변경, 추가 아트 디자인 작업은 하지 않았습니다.
검증 기록: 결과 폴더 layer_verification.json. 재현 검사: 캡처 폴더 verify_layered_review.py.

재실행
캡처 폴더 run_review.py --output 새폴더 (현재 review_config.json 사용).
기능 스위치: features.highlight_accents.enabled, 색 레이어 출력: export_color_layers=true.
--disable highlight_accents로 기존 spatial_steps 이미지만 얻을 수 있습니다.
소스/설정/코드 해시와 실행 코드 스냅샷은 각 결과 폴더에 보존합니다.
소스는 로컬 커밋 후 기존 승인된 private pixel-normalization-lab로 필터 백업합니다.
원본/생성 이미지와 Unity 에셋은 해당 원격 백업에 포함하지 않습니다.
