전체 입력·배치·규격은 `Tools/MapArt30/design.json`, 실제 생성 프롬프트는 `Tools/MapArt30/prompt.txt`다. 원본과 별도 RGBA 입력, 정규화 세부 출력은 `LocalOnly/MapArt30/run01`에도 보존했다. 생성 도구 1회, 정규화1회이며 답변 전 시각 보정/추가 생성은 하지 않았다.

두 층 방 Rect의 경계·비중첩·면적80㎡, 결과384×384·불투명 alpha·생성 원본 해시 보존을 실제 확인했다. 기존 수정 PerfectPixel 기록에는 원본색 대표 샘플을 사용한 설정을 보존했다. 팔레트 제한·명암/선 재작성은 하지 않았다. 정규화는 셀 미만의 디테일에 손실 가능성이 있는 변환이며 무손실 격자 복원이라고 주장하지 않는다.

**현재 결과는 공간 전체의 정지 아트 검토본**이다. 중앙 인물은 비율 표식이다. 생성기가 문·계단·가구 세부/장식을 재해석했으며 모든 픽셀이 치수 평면과 일치한다고 검증하지 않았다. 레이어별 오브젝트 분리, 실제 캐릭터 가림·동적 조명·Unity 배치, 상층/외관 픽셀 제작은 하지 않았다. 각도·비례·픽셀크기·색감의 유지/수정은 사용자 답변을 기다린다.

제어 이력: 최초 WorkLoop의 prepare/normalize 자원명이 중복돼 normalize 성공 직후 unknown_guard가 발생했다. 원본 상태와 실제 출력/해시를 보존하고 final validation만 별도 그래프로 실행했다. 결과 errors=[]로 review에 도달했다. 수정된 전체 그래프의 새 생성 재실행은 하지 않았다.
