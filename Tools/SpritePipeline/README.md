# Sprite Pipeline

GPT 이미지 프롬프트·Grok 동작 프롬프트·최종 프레임 수(1–16)를 입력하는 로컬 프로그램입니다. `Start.bat`를 실행하면 화면이 열립니다. 최초 Chrome 확장 설치는 [SETUP.txt](SETUP.txt)를 따릅니다.

## 간단한 사용법

- **전체 실행**: 새 GPT 이미지부터 최종 파일까지 진행합니다.
- **구간별 실행**: GPT 이미지만 / Grok 영상 / 프레임 준비 / PerfectPixel 버튼으로 해당 구간만 실행합니다. 구간 입력 파일을 선택하거나 가장 최근 중간 결과를 사용합니다.
- **전체 루틴 ON**: 구간 버튼으로 시작한 작업을 남은 구간까지 이어갑니다. 동시에 아래 Inbox의 새 파일을 로컬에서 1초 간격으로 감시합니다. 생성 요청이 없는 동안 외부 서버를 조회하지 않습니다.
- **OFF·중단**: 새 작업을 시작하지 않고 현재 구간이 파일을 저장하면 멈춥니다. '재개'는 저장된 파일부터 이어갑니다. 원격 서버에 이미 보낸 생성 요청을 취소하는 버튼은 아닙니다.

감시 폴더는 `LocalOnly/SpritePipelineRuns/Inbox`입니다. `images`에 이미지 한 장, `videos`에 영상 한 개, `frames/묶음이름`에 PNG 프레임 묶음을 넣습니다. frames에는 설정한 최종 프레임 수만큼 파일이 있어야 시작합니다. 파일 크기·수정 시각이 2초 동안 같으면 저장 완료로 간주하고, 같은 파일은 다시 처리하지 않습니다. 복사 중인 파일은 `.part` 확장자를 쓰고 저장이 끝나면 본래 확장자로 바꾸는 방식이 가장 명확합니다.

파일 선택은 이미지 PNG/JPEG/WebP, 영상 MP4/WebM/MOV, 프레임 RGBA PNG 1–16장을 받습니다. PNG 묶음은 이름 순서로 사용하므로 `frame-00.png`처럼 번호를 붙입니다. 픽셀 변환에 직접 넣는 PNG는 같은 정방형 크기(512 이상)의 투명 프레임입니다. 외부 PNG에는 시간 정보가 없으므로 기본 전체 1초이며, 프로그램에서 준비한 프레임은 영상의 원래 시간 정보를 유지합니다.

## 실행 경로

`ChatGPT 구독 이미지 페이지 → 전용 확장의 이미지 파일 전달 → 정방형 캔버스 → Grok 로그인으로 영상 생성 → FFmpeg로 N장 선택 → 기존 chroma 제거 → 수정 PerfectPixel → 공통 팔레트 → PNG 시트/JSON/GIF/WebP/ZIP`

AI 모델은 이미지·영상 생성에 사용합니다. 이후 단계 순서, 파일 완료 확인, 추출, 픽셀화, 저장은 고정 코드가 실행하며 텍스트 AI 에이전트 호출은 없습니다. 기존 sprite-gen과 수정 PerfectPixel을 직접 재사용합니다. 생성 후 GIF를 분해해 원래 GIF로 재조립하는 실험이 아닙니다.

별도 OpenAI API 키 경로는 없습니다. GPT는 현재 웹에서 제공하는 이미지 모델을 사용합니다. 관측한 웹 제목은 이미지 2.5이므로 2.0 고정을 보장하지 않습니다. Grok은 기존 `grok login` 자격 증명을 사용하고 별도 API 키 source는 거부합니다. HTTP 전송 자체는 설치된 sprite-gen 모듈이 처리합니다. MCP는 이 실행기의 필수 조건이 아닙니다.

## 현재 검증과 한계

- 구간 분리 전 버전에서 기존 실제 960×960, 6.04초 영상으로 16프레임 후처리 1회 실행: **18.34초**(ZIP 포함). AI/생성 서비스 호출 0회. 새 구간 분리 버전의 처리 시간은 재측정하지 않았습니다.
- 세부 계측: 영상 정보 0.39초, 프레임 추출 0.34초, 배경 제거·프로세스 시작 3.18초, PerfectPixel 12.08초, 공통 팔레트 1.47초, 출력 0.63초. 프로세스 4개 사용. 입력·PC 부하에 따라 달라집니다.
- 위 실험에서는 원본 16장 PNG, PNG 시트, GIF/WebP의 파일 디코딩·크기 검사를 통과했습니다. 이후 사용자 정정에 따라 반복 검증과 출력물을 다시 여는 검사를 제거했습니다.
- 최신 구간 버튼·파일 입력·폴더 감시·중단은 코드로 추가했으며, 사용자 요청에 따라 추가 테스트나 실제 입력 재처리를 실행하지 않았습니다.
- **브라우저 확장을 실제로 설치해 새 이미지를 생성하고 Grok까지 이어 가는 전 구간 검증은 아직 하지 않았습니다.** 생성 비용을 쓰는 테스트를 수행했다고 주장하지 않습니다.
- 확장은 관측한 한국어 ChatGPT DOM에 종속됩니다. 이미지 로드와 3초 안정성은 최종 파일 완성에 대한 휴리스틱입니다. 중간 이미지 노출·늦게 로드되는 과거 이미지·페이지 변경은 알려진 실패 가능성입니다. 이 부분은 첫 실사이트 실행으로 검증해야 합니다.
- 전체 10초 완료는 달성하지 못했습니다. 공급자 생성 시간은 위 18.34초에 포함되지 않습니다. 현재 가장 큰 로컬 병목은 PerfectPixel 계산입니다.

계측 원본은 `LocalOnly/SpritePipelineRuns/offline-benchmark-20260913/result.json`과 `export-1/report.json`입니다. 선택 정책이 기존 승인 결과와 다른 새 실험이며 기존 승인된 파일을 교체하지 않았습니다.

## 중단·재개

작업마다 별도 폴더와 제출 기록을 남깁니다. 입력 파일이 저장된 뒤 실패하거나 중단하면 화면의 재개 버튼으로 저장된 단계부터 진행합니다. 프로그램을 켤 때 폴더 감시는 항상 OFF이며, 저장된 작업을 읽기만 하고 자동으로 생성을 실행하지 않습니다.

Grok 요청 ID가 있으면 같은 요청을 조회합니다. 서버 요청을 보냈으나 ID 수신이 불명확하면 중복 비용 방지를 위해 멈춥니다. 기존 결과는 덮어쓰지 않으며 후처리 재개는 새 export 폴더를 사용합니다. 브라우저 연결 토큰과 서비스 자격 증명은 job.json에 기록하지 않습니다.

## 환경과 개발 확인

현재 PC에 설치된 Python 3.12, sprite-gen, FFmpeg, libwebp, 수정 PerfectPixel 경로를 `runtime.py`에서 찾습니다. 다른 PC에 배포 가능한 독립 패키지는 아닙니다. 경로 재설정은 git에서 제외한 `settings.local.json`으로 가능합니다.

```powershell
& "$env:USERPROFILE\.codex\visualizations\2026\09\10\01a08c0e-bbf2-7d10-b1e8-607c2c27f6d3\sprite-gen-trial\venv312\Scripts\python.exe" -X utf8 -m unittest discover -s Tools/SpritePipeline/tests -v
```

좌표·시간·색·실패 기준의 원본은 [DESIGN.md](DESIGN.md)입니다. 브라우저 권한과 알려진 제약은 [확장 README](browser-extension/README.md)에 있습니다.
