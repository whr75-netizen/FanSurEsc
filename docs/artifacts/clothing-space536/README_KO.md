# 536 — 전체 공간 목적식의 입력 동등성 검토

**현재 폐영역 자료에 원문과 같은 전체 공간 점수를 계산할 전제가 충족되지 않았습니다.** 개별 항·상수 실험을 추가하지 않았습니다. 원문 정의와 현재 표현의 차이를 묶어서 명세하고, 기존535 결과의 원인만 분해했습니다. 새 공간 평가·선택기·제품 수정·Unity 실행·촬영은0입니다. 논문 전체를 성공·실패로 판정하지 않습니다.

## 하나의 공간 목적식

[Feature-Aware Pixel Art Animation](https://yongliangyang.net/docs/pixelAnim_pg16.pdf)의 §4.1/Algorithm1/Appendix A를 확인했습니다. 시간 항을 제외하면 논문 가중치는 다음과 같습니다. 가중치 탐색은 하지 않았습니다.

`Espace = Eso + 0.5 Esc + Eqs + 0.5 Eqj`

| 항 | 필요한 공통 입력 | 현재 자료와 차이 |
|---|---|---|
| 방향 Eso, Eq1 | 대응 선의 방향·호길이 매개화·동일 시작점 | 폐곡선은 있으나 출력 픽셀 중심선/closed-loop phase 대응 미정 |
| 위치 Esc, Eq2 | 변형된 고해상도 원본 선 대역의 가중 coverage | 셀 **채움 면적 A**는 그 값이 아님. 원본 픽셀 선 대역·변형 입력 미보유 |
| 폭 Eqs, Eq3 | 동일 선 표현의 극값·폭과 참조 필터 | 535의 셀 모서리/중점/목록 제외는 원문 픽셀 경로/참조 perturbation과 다름 |
| 계단 Eqj, Eq4 | 출력 선의 극값별 ordered span과 고정 초기 span 수 | 영역 주변 길이·8이웃 비용은 이 값이 아님 |

원문 출력선은 span 및 픽셀 중심을 이용해 벡터화합니다. 위치 항은 원본 픽셀 선을 먼저 고해상도에서 변형한 대역을 사용합니다. 따라서 현재 mask에서 임의로 선을 골라 면적 A를 coverage로 넣는 방식은 원문의 빈 산술을 채우는 작업이 아닙니다. 위 네 항은 같은 참조·출력 선 표현을 공유해야 합니다. 상세 데이터 계약은 `SPATIAL_CONTRACT536.json`에 있습니다.

## 정상 끝 생략 선호의 정확한 원인

기존535 결과만 분해했습니다. 새 점수 실험이 아닙니다.

- 정상 끝의 참조 극값3개는 H0.75/W3입니다. 출력과의 거리는 **0.25/0/0.25셀**로 모두 반경2 안입니다. 제외 전 대응은 존재하며 폭 비용은 각각0입니다. 검색반경이나 가까운 다른 끝으로의 오매칭 때문에 실패한 사례가 아닙니다.
- 535는 H<1인 참조를 목록에서 제외했습니다. 그 결과 출력 극값3개가 각각1/3을 받아 합1이 됐습니다. 원문이 설명한 참조 기하 perturbation을 구현한 것이 아니므로 수치1은 **535 대조값**입니다.
- 폭 항은 출력 극값에 비용을 더합니다. 생략한 참조 끝의 개수를 따로 더하는 대칭 항은 이 항에 없습니다. 두 끝을 없애면 해당 출력 항도 없어지고 남은 W11 항의1/11=.090909만 남습니다.
- 동시에 방향·위치·계단 항을 넣지 않았습니다. 따라서 이것은 **의도적 참조 제외 + 출력 방향 비용의 소멸 + 다른 공간 항 누락**의 결과이며, 원문 전체에서도 정상 끝을 지운다는 증거가 아닙니다. 회전·직선분할8자료가 같은 분해를 보입니다.

43/50/44와8정상끝을 위 전체 목적식으로 평가한 합계는 모두 **미정(null)**입니다. 빠진 항을0으로 넣거나535 점수를 원문의 Eqs로 인증하지 않았습니다. 기존 43/50의 국소 개선 순위와44의 폭 항 불변은535 진단 범위로만 남깁니다.

## 구현 여부와 최소 의존성

현재 `ClothRegion524.Prepare`는 `Source → FitArea532 → 셀 면적 → SelectRegions`를 거칩니다. `SelectRegions(float[] areas, width, height)`는 셀 면적과 주변 길이를 받으며, 선/참조 대역/초기 span 정보를 받지 않습니다. 네 항을 별도 픽셀 벌점으로 더해도 원문의 목적식이 되지 않습니다.

기존 투영 기하·곡선·표면 패킷·공통 Gate는 재사용 가능합니다. 필요한 최소 전제는 **한 포즈에서 동일 경계를 나타내는 참조 선, 출력 픽셀 경로, 외곽선 대역, 채움 영역의 공통 대응**입니다. 자동 입력 어댑터가 이 계약을 제공해야 하며 사용자에게 수작업으로 선을 그리라는 결론이 아닙니다. 셀 모서리를 픽셀 중심으로 간주하거나 일정 거리 대역을 새로 합성한다면 그것은 명시적인 영역용 변형 방법으로 검증해야 합니다. 원문의 변형된 저작 픽셀 대역과 같다고 부를 수 없습니다.

참조는 후보 근사와 독립적으로 고정하고, 최종 경계 선택 단계가 위 대응을 받아야 합니다. FitArea는 참조를 덮어쓰면 안 됩니다. 선택한 닫힌 영역은 기존 Prepare/채움/외곽선/합성 Gate가 계속 공유해야 합니다. 이번 공간 검토에는 포즈 간 시간 대응·상태 뱅크가 필요하지 않으며, 이를 새 차단 조건으로 추가하지 않았습니다.

**다음 선택기 구현은 보류합니다.** 현재 자료에서 원문 동등성은 확인되지 않았습니다. 새 대형 엔진이 필연적이라는 증거도 없으며 구현/비용 측정을 하지 않았습니다. 입력 표현을 확정하지 않은 채 항별 실패나 임의 가중치 실험을 더하지 않습니다.
