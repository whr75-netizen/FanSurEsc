# 535 — 고정 참조 극값·폭 항의 한정 오프라인 적용 검사

**폭 항 단독 적용은 정상 끝 생략 반례에서 실패했습니다. 제품에 적용하지 않았고 Unity 실행·새 촬영·상수 탐색은 없습니다.** 43/44/50 및 기존 회전×직선분할 8정상끝 자료만 재사용했습니다. 이것은 논문 전체 방법의 구현이나 실패 판정이 아닙니다.

## 원문과 이번 대조의 구분

[Feature-Aware Pixel Art Animation, §4.1, Fig7, Eq3](https://yongliangyang.net/docs/pixelAnim_pg16.pdf)는 고정된 변형 참조선과 출력선의 극값을 비교합니다. 극값 높이는 이웃 극값과의 작은 수직 차이, 폭은 높이0.5픽셀 범위의 수평 길이이며 두 축을 다룹니다. 참조의 높이1픽셀 미만 특징을 걸러내고, 실험상2픽셀 안에서 대응을 찾습니다. 대응하면 폭 차이/폭 합, 대응이 없으면 1/폭을 평가합니다. 논문 전체는 이 항 외에 방향·위치 유사도(Eq1/2), 계단 품질(Eq4)도 사용합니다.

0.5/1/2는 여기서 **논리픽셀 좌표에 정의된 논문 설계 상수**입니다. 해상도에서 유일하게 도출되는 자연상수나 모든 모델의 최적 수치가 아닙니다. 현재480×272/native2에서 길이1논리셀은 화면2픽셀입니다. world/source에서는 해당 투영 pitch로 환산해야 하며, 일반 해상도 자동정책을 구현하지 않았습니다.

이번에는 각 포즈의 저장 pre-Fit Source 폐곡선을 후보와 독립적으로 고정했습니다. FitArea532 또는 최종 선택 결과를 참조로 다시 생성하지 않았습니다. 단, 이 Source도 상류 opacity 사슬 근사를 거친 것이므로 원시 메시·저작 feature line과 같다고 주장하지 않습니다. 포즈 간 지속 feature ID도 인증하지 않았습니다.

출력은 저장된 영역 마스크를 기존 HeadRegion502.Boundaries의 방향·순환 규칙으로 경계화했습니다. 논문의 저작된 1픽셀 선 중심 경로와 **영역 셀 모서리 경계는 다른 표현**입니다. 평탄 극값은 중점으로 대표하고 두 축·같은 극성·반경2의 후보를 모두 기록했습니다. 해당 자료에서 분기점·다중 대응·유효 폭 미정은0이지만, 다른 링 사이의 의미적 feature-line 소유권까지 검증한 것은 아닙니다.

원문이 설명한 연속 참조선의 반복 pixel perturbation을 완전히 이식하지 않았습니다. 높이1 미만의 참조 극값은 이번 폭 항 대응 대상에서 제외하는 **eligibility 대조**입니다. 이를 논문 그대로의 최적화라고 부르지 않습니다. 무게·시간 항·후처리를 넣지 않았습니다.

## 같은 폭 규칙의 실제 점수

낮을수록 선호합니다. 아래 국소 후보는 기록된 사건 셀만 바꿔 점수 원인을 분리한 진단용 반사실이며, 셀 좌표를 제품 규칙으로 사용하지 않았습니다.

| 고정 참조 / 출력 비교 | 기존 점수 | 대안 점수 | 결과 |
|---|---:|---:|---|
| 43: 기록된 가시2셀 제거 | 2.423800 | 0.923800 | 제거 선호 |
| 50: 파인1셀 채움 | 2.992856 | 1.492856 | 채움 선호 |
| 44: 정상 계단의 기록된1셀 생략 | 1.007784 | 1.007784 | 폭 항으로 이 변화 구별 못함 |
| 정상 끝 보존 vs 기존 반셀 근사 손상 | 1.000000 | 1.083333 | 보존 선호 |
| 정상 끝 보존 vs 두 끝 모두 생략 | 1.000000 | **0.090909** | **부적절한 생략 선호** |

43과50은 각각 출력의 H1/W2 극값과 H1/W1 반대 극값이 대응 없이 1/2+1=1.5의 비용을 만듭니다. 원래 참조의 해당 높이는 각각0.409729/0.430710셀로 참조 eligibility에서 제외됩니다. 실제 계산은 동일 식으로 43 제거·50 채움을 선호하지만, 그것만으로 정상 특징 보존을 보장하지 못합니다.

정상 반례의 두 끝은 H0.75/W3이고 그 사이 국소 극값도 H0.75/W3입니다. 참조에서 제외되어 보존 출력은 1/3×3=1을 받습니다. 두 끝을 없앤 몸통 사각형 출력은 W11의 대응 없는 극값 하나로 1/11을 받습니다. 회전4×직선분할2 모두 같은 수치이며 단순히 정점 수를 바꿔 얻은 결과가 아닙니다. 참조 높이 제외를 하지 않은 **진단 대조**에서는 보존0/생략1/11로 순위가 뒤집힙니다. 이 대조는 높이 상수를 바꿔 채택하자는 제안이 아닙니다.

따라서 기존 후보 몇 개의 순위만으로 통과시키지 않았습니다. 44의 변화를 구별하는 계단 항과 정상 끝의 현재 형상·위치 근거가 폭 항에 없다는 것이 확인됐습니다. 원문 전체의 형상 유사도가 이 반례를 해결하는지는 이번에 구현·검증하지 않았습니다.

## 필요한 데이터와 교체 지점

현재 `Source → FitArea532 → CurveArea511.Compute → SelectRegions → 공통 Gate`에서 원본 특징 비교를 하려면, 근사 전 참조를 독립 보존하고 출력 후보 경계의 같은 arc/line 대응·방향·영역/가림 소유권을 제공해야 합니다. 실제 외곽선 밴드의 중심 경로와 채움 경계 사이의 좌표 계약도 먼저 같아야 합니다. reference의 필수 특징이 후보 근사에 의해 사라지면 다시 기준으로 삼는 순환이 됩니다.

판정 책임은 **최종 영역을 정하는 SelectRegions 경계 선택 단계**에 있어야 합니다. FitArea는 참조를 덮지 않는 후보 생성/가속 역할이어야 하며, 기존 이진 mask에 Eq3 벌점을 후단으로 얹어 원형 보존을 강제했다고 말할 수 없습니다. 현재처럼 개별 셀 면적+주변 길이만 입력받는 선택기에는 참조선의 형상·위치·span 정보가 없습니다.

이번 폭 항 단독 gate는 실패했으므로 그 선택기를 교체하거나 새로운 형상/시간 엔진을 만들지 않았습니다. 확인된 정보 부족은 **고정 참조와 출력의 유효한 선 대응 + 형상/위치 근거 + 계단 품질**입니다. 추가 패널티나 임계값을 누적하는 작업으로 넘어가지 않습니다. 이것이 기하만으로 모든 디자인 의도를 판별할 수 없다는 일반 증명도 아닙니다.
