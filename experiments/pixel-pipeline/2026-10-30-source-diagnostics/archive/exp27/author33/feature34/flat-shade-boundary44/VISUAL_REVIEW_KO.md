# 직접 연 출력과 판정

`before-boundary.png`, `corrected-boundary.png`, `corrected-RGB-8x.png`, `before-marked.png`, `corrected-marked.png`, `before-ROI.png`, `corrected-ROI.png`, `unconstrained-failure-corrected-labels-8x.png`를 직접 열었다. 역할색 마스크·실제 RGB·미적용 guide 선을 구분했다.

- 최종 출력의 긴 Q2/Q3 공유 경로에서 (18,14)/(17,15)/(15,16)/(10,21)의 4셀이 바뀐다. source/Q는 그대로이며 Q'에서만 변한다. 명암값을 다시 계산하거나 실제 원색을 섞어 만든 색이 아니다.
- 이 경로의 오른쪽 진행 중 끼어 있던 왼쪽 1칸 역행이 없어진다. 격자 변 수는43→41이지만 이것만을 합격 근거로 삼지 않았다. 같은 source curve의 arclength로 측정한 pixel-span 접선 오차는 .20387793→.17180815, 최대 curve-raster 거리는 .79987780→.69258833셀이다. 원래 큰 방향 전환은 모두 직선으로 펴지 않았다. 실제 run 배열은 `DIRECTION_FLOW.json`에 있다.
- 실제 RGB에서는 인접 팔레트 차이가 작아 4셀 변화가 미묘하다. 확대 라벨에서 차이는 확인되지만 이것을 전체 미감 개선으로 확대하지 않는다.
- 기존 6개 단독 셀은 모두 남는다. 각 셀의 실제 g/표면/가림 근거 없이 지우지 않았다. 전체 머리의 분단/고립 문제가 해결된 결과가 아니다.
- 이전 실패 반례에서는 (9,29)의 변경이 (8,29)의 Q1 연결을 끊어 새 단독 셀을 만든다. 접선 수치가 좋아졌어도 미채택했다. 이 실패 이미지는 이전 내부 시험이며 최종4셀판과 source 지원 범위 조건이 다르므로, 둘을 한 조건만 바꾼 A/B라고 하지 않는다.
- 부드러운 참조 곡선 선은 별도 `curve-reference-overlay.png`다. 최종 픽셀 경계는 `corrected-boundary.png`의 실제 격자 경계이며, 참조선을 그렸다는 사실로 픽셀 보정 완료를 주장하지 않는다.

## 한계

정지 frame95 하나의 제한 후보다. g 변화에 표면 노멀·직접광·그림자가 각각 얼마나 기여했는지 이번 입력만으로 전부 분해하지 않았다. 실제 앞뒤 표면과 표본 선택의 기여, Q 산술의 정확성까지 구분했다. 움직임·실시간 GPU·눈/얼굴 교정·전체 모델 미감은 검증하지 않았다. 제품·31·34·Unity·Desktop은 변경하지 않았다.
