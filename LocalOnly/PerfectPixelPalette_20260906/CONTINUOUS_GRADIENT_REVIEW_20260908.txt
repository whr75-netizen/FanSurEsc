현재 재개 지점 — 2026-09-08 / 원본 연속 그라데이션 기반 단계화
작업 기록이며 전역 AI 지침이 아닙니다.

문제와 변경
- 이전 연결 수정 2d2dae7은 명암 함수를 실행하게 했지만, base_grid/4의 SLIC 조각별 1~3톤을 그대로 사용했습니다. Chibi는 3499개 조각이었습니다.
- 새 gradient_tones.py는 출력 grid를 인자로 받지 않습니다. 원본 4방향 이웃의 색 연속성으로 영역을 키우며 픽셀 반경, 고정 블록 면적, 최소 조각 크기로 자르지 않습니다.
- Oklab (a/L,b/L)은 같은 바탕색에 중립 밝기 배율을 곱한 영향을 분리합니다. 그룹 전체 색 성분의 허용 폭으로 연속적인 색상 연결이 무제한으로 합쳐지는 것도 제한합니다. 급격한 색 경계/투명 배경은 넘어가지 않습니다.
- 각 전체 영역에서 실제 원본 대표색 1개로 시작하고 가장 오차가 큰 색을 추가합니다. 모든 원본색의 최근접 대표색 Oklab 거리가 color_error 이내가 되면 멈춥니다. K=3 상한, 재분할 조각별 참조색 교체, 명도 범위 강제 확대가 없습니다.
- 색 성분도 평가하므로 밝기가 같은 분홍/피부색도 구별합니다. 대칭/비대칭 형태나 볼·몸 같은 이름으로 분기하지 않습니다. 볼터치/바탕/조명의 원래 합성 레이어를 복원하는 기능은 아닙니다.
- 실제 색 치환은 한 영역의 공통 팔레트로만 합니다. 평균 RGB를 출력하지 않고, 대표 RGB는 해당 영역의 원본에서 고릅니다.

현재 실행
../ChibiPixelReview_20260908_Bright/Run_Bright_Review.cmd
기본 config: 같은 폴더 review_config.json
기본 출력: 같은 폴더 result_continuous_96 (기존 폴더가 있으면 덮어쓰기 거부)
재실행은 Run_Bright_Review.cmd --output 새폴더
원본은 source_bright_rgba.png, 기존 reference도 같은 원본입니다.
설정: region_tones.mode=continuous, color_error=.06,
gradient_edge_threshold=.06, gradient_chroma_span=.12.
color_error를 줄이면 원색 오차를 더 엄격히 제한하여 색 단계가 늘 수 있습니다. 키우면 더 단순해지지만 옅은 특징이 사라질 수 있습니다. 단순화 강도는 명시적인 색 공간 오차이며 이미지 크기 상수가 아닙니다.
기존 tones/min_retained_tone_delta_l은 legacy_regions 모드의 설정입니다. continuous에서는 위 새 설정을 사용합니다.
공유 API: prepare_region_tones(mode=continuous), BoundaryOptions(shading_mode=continuous).
continuous는 원본색 단계화 전용이며 다른 참조 이미지를 전달하면 명시적으로 거부합니다. Canva 참조 팔레트 이식은 기존 legacy_regions 모드/고슴도치 설정 그대로 보존합니다. 자동 fallback은 없습니다.

결과와 실제 검증
- 동일 원본으로 96x192 RGBA 비교본 1회 생성. 왼쪽 원본 / 가운데 이전 region_tones / 오른쪽 continuous.
- source 단계 554연결영역, 원본색 대표 446개, 최종 격자 86색. 색 수 자체는 미적 점수나 개선 판정이 아닙니다. 작은 분리된 영역의 대표색도 보존합니다.
- 최대 관측 Oklab 색 오차 .05919758 <= 설정 .06. 픽셀 좌표 선택과 alpha는 이전 96x192 결과와 배열 비교로 동일합니다. 원본 파일과 RGBA 입력은 변경하지 않았습니다.
- 자동검사 189개 통과(새 독립 9개 + 새 통합 6개 포함). 실제 분할 경로의 가로8배 반복, 서로 다른 출력grid에서 source색/영역/팔레트 동일, 약한 명암1색/강한 명암3색초과, 동일밝기 작은분홍 특징, alpha/scope/원색 provenance 포함.
- 최초 제한 환경의 전체 검사에서는 skimage/scipy 읽기 오류가 있었으며, 기존 설치 라이브러리 접근이 가능한 환경에서 같은 검사를 통과했습니다. 라이브러리를 새로 설치하거나 다른 알고리즘으로 대체하지 않았습니다.
- 결과 폴더에 실제 실행 코드/설정/원본 사본/중간 이미지/좌표 NPZ/해시가 있습니다. 사용자 외형 검토 대기. Unity 에셋/런타임은 이번 작업에서 변경하지 않았습니다.

한계 / 다음 검토 기준
- 단일 합성 이미지로 바탕색·홍조의 alpha·색조명을 유일하게 복원할 수는 없습니다. 허용 색 오차 이하의 옅은 특징은 단순화될 수 있습니다.
- 날카로운 그림자는 같은 재질이어도 별도 영역이 될 수 있고, 떨어진 영역끼리 공통 스타일 팔레트는 아직 공유하지 않습니다.
- 그룹 병합과 대표색 선택은 결정적 휴리스틱입니다. 전역 최소 색 수, 모든 이미지/회전/재압축에서의 불변성이나 디자인 최적성을 보장하지 않습니다.
- max_pixels/max_domains/max_colors는 계산 자원 상한이며 초과 시 오류입니다. 이를 이미지 공간 크기나 강제 색 단계 수로 쓰지 않습니다.
- 새색단계와 선정규화의 동시사용은 기존처럼 거부합니다. 이번에는 명암 계산만 고쳤고, 선/포즈/형태를 추가 수정하지 않았습니다.
