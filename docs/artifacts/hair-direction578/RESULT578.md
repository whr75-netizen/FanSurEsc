# 578 정면 헤어 방향 검증

577 알고리즘을 바꾸지 않고 새 방향 yaw170의 입력 생성부터 실제 Walk 81쌍까지 검증했다. 기록 578은 새 적용 버전이 아니다. 제품 헤어 영역 모드는 기본 OFF이며, 전방향 자동 차트 생성·교체는 미완료다.

## 방향과 입력

실제 카메라의 수평 방위는 캐릭터 기준 약168.9183°다. yaw80/260은 양쪽 옆모습이고, 이번 yaw170은 정면에 가깝다. `PlayerMovement.UpdateFacingDirection`은 연속 회전을 사용한다. 준비된 두 차트만으로 모든 이동 방향을 지원한다고 말할 수 없다. 상세 범위는 [방향 표](DIRECTION_MATRIX578.md)를 따른다.

실제 Walk70의 변형 헤어 메시, UV, 투영, 원본 bind 서명을 한 번 추출했다. 기존 `compile_curve511.py`가 동일한 계수로 원본 20개 경계·608점에서 2개 폐곡선·92개 anchor를 자동 생성했다. 전처리 4.4913초와 매포즈 갱신은 별개다. 수동 좌표/방향별 임계값 편집이나 원본 3D 메시 수정은 없다. 입력 생성기 호출과 주입은 검증 스크립트가 조율한다. 제품 내부의 자동 시점 적합성 검사·재생성/교체는 구현되지 않았다.

## 실제 결과

- 실제 연속69–73번 다섯 쌍 후 전체 0–80번의 81쌍을 한 번 실행했다. 원본960×544 PNG 162장은 기존 작업 위치에 보존하며 프로젝트 산출물에 복제하지 않는다.
- OFF는 같은 정면 곡선 입력의 signed selection566, ON은577 영역 경로다. 제품 기본 OFF와 비교한 영상이 아니다. 양쪽 Clothes547 ON, Body0 영역 OFF이며 카메라·해상도480×272·포즈·시간·조명은 쌍별 일치한다.
- 영역 소유권 일치, 경계 밖 쓰기0, 새 닫힌 구멍0, 동일 비헤어 표면 RGB차이0, 머리ROI 밖 전신 차이0, 미지원 표면 공급0이다. 이 수치만으로 픽셀아트 품질 통과를 판정하지 않고 전체 머리 연속표와 전신 비교를 함께 검수했다.
- 얼굴 38개 표본은 저장된 실제 삼각형/UV/알파/같은 source-ray 깊이로 대조했다. 앞 불투명 얼굴을 잘못 덮은 표본0, 근거 누락0이다. 원본 눈 입력은 같지만 눈 가시성 버퍼는 1셀 다르다.
- 정면의 음의 가족은 이번 루프에서 모두 FILL이었다. KEEP 검사가 비어 있는 것을 큰 가르마 보호의 새 통과 근거로 세지 않는다. 기존 옆모습의 큰 틈/양의 형태는 저장 입력 회귀로 확인했다.
- 기존 yaw80/260 각81개, 총162개 실제 저장 입력을 현재 제품 선택기로 재계산했다. 선택 마스크·보호 양의 형태·envelope 위반 차이0이다. 새 옆모습 촬영으로 세지 않는다.

## 15번 눈 1셀 변화의 계산

논리셀(214,51)의 약한 윗속눈썹 feature7이 14/15/16에서 기준566은7→7→0,577은7→0→0이다. 홍채·동공을 바꾸거나 눈 재질을 대체한 것이 아니다. 기존 영역화로 가림 전환이 한 프레임 앞당겨진 차이다.

해당 셀 원본 양의 면적은 .4265284240→.4912036657→.5530682802다. 15번의 작은 닫힌 틈 폭은 .6376427897 논리px, 면적 1.1021932731셀²이며 기존 FILL 계약을 따른다. 15번에서 머리 선택이0→1로 달라지고 `EyeFeature348.compute:Evaluate`의 `_HairMETA` 가림 분기가 약한 선을 가린다. 새 분기나 선색 패치는 추가하지 않았다.

머리 Hair/1 primitive1253 패킷의 투영은 정확히(214.5,51.5), UV(.31806591,.42288950), cameraZ13.67579861이다. 같은 ray의 가장 앞 얼굴은 Skin/3 primitive2241, 알파1, cameraZ13.70639241로 뒤에 있다. 기존 눈 승자 깊이도 head-camera 기준 약 13.71484392로 뒤다. `EYE_CHANGE578.json`에 원본 값·인접 포즈·기존 ray 근거를 보존했다. 이를 ‘눈 차이0’이라고 표시하지 않는다. 모든 eye subpixel ray/world 가림을 새로 검증했다고 주장하지 않는다.
