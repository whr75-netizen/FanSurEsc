# 상태 비용520 최소 계약과 적용 실패 경계

이 작업은 519 대응과 현재 형태 비용을 고정하고 시간 상태 비용의 의미만 시험합니다. 제품/Unity/색/RGB 후처리/추가 mask 선택층은 바꾸지 않았습니다. 새 비용은 기존 선택기 안에서 평가할 계약이며 현재516의 탐색에 통합되지는 않았습니다.

`E_t(x)`는 기존 면적 오차+8이웃 perimeter 비용입니다. `K_t(x,y)`는519의 유효한 기하 대응에서 얻는 span 편집 비용입니다. 실제516의12셀 고정 반례는519로 재검증했으며 양쪽 drawing 모두 대응됐고, 복귀 raw편집비용은42가 아닌36입니다. 현재 형태의 공간 이득은2.042562276124954입니다.

기존 `E_t(x)+βK(previousOutput,x)`는 출력되지 않은 대안을 잊습니다. 같은 현재 근거가 계속되어도 매번 같은 편집 장벽을 처음부터 비교하기 때문에 영구 고정될 수 있습니다. 새 최소 계약은 같은 선택기에서 허용되는 대안마다 이전 최적 이력의 상대 비용 `V(x)`를 보유하는 것입니다. 최종 mask를 다시 거르거나 별도 output selector를 얹는 방식이 아닙니다.

## 갱신 정의

1. 계수는 기존 `β=float32(.14)×η`, η=.5/1/2를 유지합니다. 고정 시간 기준 `r`은 원래81개 기록의 `gameTime` 간격 중앙값0.01666666666666572초입니다. 이 값은 원래 계수의 기준 간격을 보존하며 현재 FPS나 두 ABA를 보고 조절하는 시간이 아닙니다. 초기1초 기준 시도는 강도 보정을 바꿔 비교를 혼동하므로 `SecondsCalibrationV1`로 보존하고 미채택했습니다.
2. 같은 현재 기하에서 허용된 대안 사이의 raw 편집 edge를 바꾸지 않고, 명시적인 유효 편집 경로의 비용 합으로 도달 비용 `D`를 구합니다. 다단계 경로가 direct편집보다 싸면 그 경로를 기록합니다. 예를 들어 합성3상태의 direct10 대신2+2가 쓰이는 것은 원래 edge를 낮춘 것이 아닙니다. 이 envelope가 없으면 비삼각 비용에서 시간 분할 성질이 깨질 수 있습니다.
3. `C_D(z)(y)=min_x(z(x)+D(x,y))`로 정의합니다. 현재 근거 `R_t(x)=E_t(x)-min E_t`는 공통항을 제거한 형태 오차입니다. 유효한 같은 기하 구간에서는 `V_new=C_D(V_old+(dt/r)R_t)`를 계산하고 공통 최소값만 빼 정규화합니다. 출력은 동일 목적식의 최소 상태이며 동률은 현재E와 안정된 상태 키로 결정합니다.
4. 이력 갱신은 **측정된 현재 형태의 상대 손해**에만 반응합니다. dt=0이나 동일한 근거에는 별도 시간 counter/decay가 없습니다. 현재 형태의 지속적인 이득δ가 있고 복귀할 대안이 보존되어 있으면 유한 비용D를 넘은 뒤 복귀할 수 있습니다. 정지2상태에서는 이론 복귀 시간 `D×r/δ` 이내이며 관측 출력은 다음 표본 시점까지 늦을 수 있습니다.
5. 실제 운동은 유효한 기하 대응이 운반합니다. 같은 디자인 상태를 유지한다고 화면 좌표를 고정하지 않습니다. 현재 최소 운동 시험은 유효한 동반 이동 대응이 제공됐을 때의 kernel 성질이며 실제Walk 품질 결과가 아닙니다.

## 재시작과 초기 조건

가림/분리/통합/생성·소멸로 무효화된 성분의 이전 endpoint 대응은 UNAVAILABLE입니다. 새 상태로0비용 대응했다고 부르지 않습니다. 바뀌지 않은 성분의 이력을 남기려면 기존 결합 상태 비용을 무효 성분에 대해 최소화해 주변화하고, 현재 새 성분에는 이전 형태를 강제하지 않아야 합니다. 전체 이력을 지우는 반례는 무관한 성분까지 바꾸므로 실패입니다.

따라서 현재 후보/상태 표현은 유효한 주변화 결과와 현재 가능한 조합을 표현할 수 있어야 합니다. 두 완성 drawing만 보유하는 bank가 독립적으로 가능한 결합을 빠뜨리면 이를 성공 처리하지 않습니다. 현재516은 직전 출력의 spans 한 벌만 보유하므로 이 대안 값·부분 재시작 계약이 아직 구현되지 않았습니다. 기존 static+516 세 결과의4mask bank도 검토했지만6개 사건 중5개에서 서로 다른 outer/holes 조합이 빠집니다. 이 조합은 구조적 containment만 확인했으며 source/depth/가림 적격성을 인증한 것이 아닙니다. 이 bank로 재선택하는 우회는 채택하지 않았습니다.

엄격한 현재 형태 이득이 지속되는 정지 반례에서는 초기 상태 의존성이 유한 시간 뒤 사라집니다. 반면 주기 전체 근거가 같고 양쪽 선택이 편집 장벽 안에 남는 합성 주기는 서로 다른 안정 선택을 유지할 수 있습니다. 모든 루프 시작 상태가 동일해진다는 보장은 없습니다. 이것을 실제Walk의 디자인 품질 통과로 바꾸지 않습니다.

## 현재 판정

- 실제 정지 반례에서 η=.5/1/2 복귀 관측은 약33.33/50/83.33ms입니다. 복귀 시 면적 오차는36.642917→34.436335, 계단 비율 반전 진단은4→2가 되지만12셀이 한 번에 바뀝니다. 유한 복귀가 실제 시간 품질을 보장하지 않습니다.
- 한 기준 간격의 첫 선택은 원래 계수 강도와 같은 결정을 내립니다. 동일 정지 근거의30/60/120Hz 및 포화 전1/2/4/8분할 값이 일치합니다. 누락된 실제 운동 포즈를 만들어 검증한 것이 아닙니다.
- 최소 kernel 성질은 통과했지만 **기존 선택기 적용 gate는 미통과/통합 미완료**입니다. 대안 이력과 성분별 주변화를 기존 탐색 상태에 넣어야 합니다. 검증된519 대응, 현재 공간 비용, 시간 계수를 동시에 바꾸어 숨기지 않습니다.
- 이 때문에 저장Walk의 세 계수 민감도는 아직 실행하지 않았습니다. 신규 채움 가림은 계속 미확인이며 제품/Unity 촬영 보류, 내부색·성능도 별도 미해결입니다.
