# 575 내부 FILL 권한과 외부 형상 보호 분리

574의 목덜미 홈을 수정했습니다. 실제 인접 26쌍 후 같은 후보로 실제 Walk 전체 81쌍을 한 번 실행했고, 이번 실행의 동일 입력에 이전574와 수정575 선택기를 재계산해 원인 수정까지 확인했습니다. 알려진 외부 손실 15표본은 복구되고 기존 내부 틈 채움과 72번 앞머리는 유지됩니다. 검증한 yaw80의 이 수정은 통과했으며, 다른 방향 입력·패킷 비용 때문에 헤어 제품 기본값은 계속 OFF입니다.

## 최초 회귀와 계산

574는 내부 빈 영역을 머리로 합치는 과정에서 외부 선택도 `SelectRegions543(..., groups:null)`로 다시 계산했습니다. 실제 첫 외부 회귀는 8번 후두부, 첫 목덜미 회귀는 21번입니다. 21번 원본 가지 `y|L:0:49|R:0:48|cap>open-mouth`가 `(220,57)`·`(220,58)`을 묶었는데, 이 제약을 없애 아래 셀만 빠지는 해를 허용했습니다. 41번도 같은 원 가지의 `(221,57)`·`(221,58)`입니다. 삼각형/UV 공급이나 최종 가림이 최초 원인이 아닙니다.

21번 두 면적은 .496939123/.301579267입니다. 밖 이웃을 실제 기준 상태로 고정하고 기존 면적+8이웃 경계식을 계산하면 두 셀의 유지−동시생략 비용은 −.089097389로 함께 유지가 유리합니다. 하지만 그룹을 풀면 아래 셀만 생략하는 해가 두 셀 유지보다 .232821263 저렴합니다. 8번에서도 대응 값은 −.121096108과 +.025240708입니다.

그룹 전체 복구도 답이 아닙니다. 같은 72번 입력에서 앞머리 A=.485426635, 아래 셀 A=.024008663을 묶으면 두 셀 유지가 두 셀 생략보다 .653088998 비싸져 앞머리가 다시 빠집니다. 앞머리만 유지하면 두 셀 생략보다 .216883574 저렴합니다. `GROUP_COSTS575.json`은 모든 라벨 조합, `Trace575/GROUPS575.tsv`는 제거된 원 경계와 그룹 셀을 보존합니다. 프레임별 상수나 새로운 패널티로 이 차이를 맞추지 않았습니다.

## 최소 수정 / 입력과 출력

수정한 제작 소스는 기존 두 파일뿐입니다.

1. `HairRegions574.SourcePositive`가 현재 포즈의 원래 닫힌 선분곡선·원 경계 그룹·기존 면적/공간 cut으로 **FILL 이전에 유지된 양의 형상 P**를 계산합니다. 원본 메쉬 래스터나 과거 프레임 RGB를 복사하지 않습니다.
2. 기존 외부 영역 cut은 같은 면적·가중치·8이웃을 사용하되 `P ⊆ S`를 제약으로 받습니다. `HeadRegion502.SelectRegions543`의 선택적 `requiredPositive` 인자에 기존 hard-link와 같은 용량 100000을 source→해당 셀에 전달합니다. 면적값을 1로 덧칠하거나 선택 후 마스크를 OR 합성하지 않습니다.
3. 내부의 빈 셀은 고정하지 않습니다. 기존 작은 가족 FILL/큰 가족 KEEP·소유권·입구 보호는 그대로 실행하므로, 72번의 별도 양의 끝을 내부 음의 셀과 강제로 다시 묶지 않습니다. FILL의 권한이 이미 유지한 바깥 머리를 지우는 데까지 확장되지 않게 한 것입니다.

작은 틈 기준 2논리픽셀, 곡선·경계 ID, UV/색/깊이·512/513/550 가림·Draw/Gate는 변경하지 않았습니다. 후단 필터, 시간 이력, 모델/좌표/프레임 특례나 새 메시가 없습니다. `UseRegionFamilies574` 기본 OFF인 기존 대안 경로 내부의 수정입니다. 기존 563/566 선택기에 또 다른 출력 필터를 덧붙이지 않았습니다.
