## 전달된 해상도 연구와 현재 미적용 범위

부모가 전달한 Zheng/Sederberg2000의 곡선 subdivision 오차한계(Δt≤sqrt(8ε/D), D≥sup||C''||, 호길이에서 Δs≤sqrt(8ε/κmax))는 현재 구현하지 않았습니다. 현재 입력은 분절 직선이므로 모서리를 건너는 구간에 C²곡선의 식을 그대로 적용할 수 없습니다. 픽셀오차 εpixel을 source pitch p로 εsource=εpixel*p로 환산할 수 있다는 관계와 픽셀아트 디자인 최적 수치를 선택하는 문제는 별개입니다.

Mokhtarian/Mackworth1992 Gaussian scale-space의 σ도 현재 미적용입니다. 평활화는 원형을 바꾸며 단순 샘플 수 증대와 다릅니다. Feature-Aware2016 §4.1/Fig7/Eq3의 참조선 extrema/끝↔출력선 대응과 .5px 폭 평가도 미적용입니다. 현재 cut은 최종 이진 영역만 반환하며 해당 feature-line 대응을 검증하지 않았습니다. 정상8마스크 동일을 논문 대응 통과로 바꾸지 않습니다. 공간 term 검토와 과거 시간DP는 분리하고 추가 구현/상수탐색은 보류합니다.
