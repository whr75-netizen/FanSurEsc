# D20 — 생성 기준 이미지와 실제 3D 재현의 한정 실험

최종 결과: 실루엣 IoU95.57272%, 전경 RGB 허용오차8 비율50.05545%로 **99% 조건 미달**. 실제 모델/기준/비교는 `LocalOnly/DeskReference20/`에 보존했다. 추가 임의 미술 보정은 중단했다. 전체3D/NPR방식의 불가능성을 증명한 결과는 아니다.

## 요구 → 결정

사용자 요청: 생성형 픽셀 책상 한 장을 고정하고 실제 3D로 99% 이상 동일하게 재현할 수 있는지 시도한다. 안 되면 결과와 한계를 남기고 멈춘다. 기존 Unity 씬과 D19까지의 책상은 보존한다.

이 실험은 자동 3D 복원 제품이나 미술 완성을 주장하지 않는다. 고정 기준에 대한 한 번의 재현이다. 원본 생성 이미지의 불일관성도 모델의 개별 부품 변형으로 숨기지 않는다.

| 후보 | 결정 |
|---|---|
| 기존 조명/포스터화의 반복 조절 | 제외. 이전 결과가 이미 요구에 미달했고 이번 입력은 새 기준이다. |
| 기준 RGB 전체를 카메라에서 투영해 같은 시점으로 재출력 | 제외. 동일 입력의 재출력을 3D 스타일 재현 성공으로 오인한다. |
| 형상 제약의 최소제곱 추정 + 기준에서 추출한 목재 + 로컬 UV + 면 색/접합선 | 이번 최소 실험. 형상·색·가림의 실패를 각각 관측할 수 있다. |

## 입력과 권위

- 생성 원본은 변경하지 않고 `LocalOnly/DeskReference20/reference.png`에 복사한다. 원본 크기 1536×1024.
- 도구: Blender 5.2의 실제 솔리드 메시/깊이 래스터화, NumPy 최소제곱, Pillow 재료 좌표변환/비교판.
- 표준 근거: [Blender orthographic camera](https://docs.blender.org/manual/en/latest/render/cameras.html), [Emission](https://docs.blender.org/manual/en/latest/render/shader_nodes/shader/emission.html), [NumPy least squares](https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html).
- 생성형 그림은 목표 외형이며 정확한 CAD 도면이 아니다. 측정한 랜드마크에는 수 픽셀 오차가 있으며 추정 결과/잔차를 보존한다.
- 기준 이미지 상판의 목재만 평면 좌표로 펴서 재료로 사용한다. 기준 전체/각 화면 위치의 색을 출력 위치에 직접 되돌려 넣지 않는다. 다른 부품은 같은 재료의 로컬 UV를 재사용한다.

## 수학적 계약

오른손 좌표계, 미터. X=폭, Y=뒤쪽 깊이, Z=위. 모델 높이 H=0.74는 단일 이미지의 절대 크기 불확정성을 고정하는 가정이다. 너비/깊이/다리 너비와 카메라는 공통 매개변수다.

`r=(cosφ,sinφ,0)`, `u=(-sinφ sinθ,cosφ sinθ,cosθ)`.
`sx=ox+P(r·p)`, `sy=oy-P(u·p)`. P>0, 0<θ<π/2. 단일 직교 카메라와 공통 투영이다.

4개 다리는 같은 너비 L, 높이 H-T이며 중심은 `(±(W/2-I-L/2), ±(D/2-I-L/2), (H-T)/2)`다. 모든 발 Z=0, 상단 Z=H-T. 부위별 화면 offset/scale/rotation 보정은 없다. 조립부와 서랍은 같은 치수에서 계산한다.

실제 광원 0개, world=0. 최종 출력은 로컬 목재 UV × 면 역할별 색의 emission(1)이다. 강도 1은 텍스처 색을 표시하는 값이며 100% 외부 조명/노출을 더한다는 뜻이 아니다. 부드러운 광원 감쇠·specular·AO를 사용하지 않는다. 접합선은 면의 물리적 경계에서만 계산하며 다른 오브젝트 위에 2D 선을 덧그리지 않는다. 정상적인 깊이 버퍼가 가림을 결정한다.

구현 전 독립 검토에서 원본이 정확한 8×8 격자가 아님을 확인했다. 해당 격자에 제한하면 RGB 허용오차 일치율의 낙관적 상한부터 85.504% 미만이다. 따라서 **기본 비교 렌더는 원본과 같은 1536×1024의 직접 3D 렌더**로 고정한다. 별도로 192×128을 렌더해 정수 8배 최근접 미리보기를 제공한다. 후자는 큰 픽셀 표현 참고이며 99% 비교에 사용하지 않는다. 기준 이미지 자체는 수정하지 않는다. 다른 시점 렌더도 실제 3D 구조의 보조 자료이며 기준 일치율에 합치지 않는다.

## 최종 검사와 실패 판정 — 렌더 전에 고정

1. 모든 메시 체적/크기 양수, 같은 다리 4개, 발 높이와 상판 접촉, 직교 투영 기저 직교성.
2. 기준/렌더 같은 1536×1024 좌표에서 비교. 후처리 정렬·크롭·색 최적화 없음. alpha>=128을 전경으로 판정한다.
3. 전경 합집합에서 RGB 각 채널 오차<=8이고 양쪽 모두 전경인 픽셀 비율, 실루엣 IoU, exact RGB 일치율을 별도 기록한다. 빈 배경의 일치로 점수를 부풀리지 않는다.
4. 99% 재현의 이번 수치 조건은 IoU>=0.99 및 위 RGB 허용오차 비율>=0.99다. 이 조건조차 미술적 동일성의 증명은 아니다. 실패는 실패로 종료하며 임계값/기준을 바꾸지 않는다.
5. 결과 이미지와 실제 `.blend`, 입력·추정치·잔차·측정 결과를 함께 보존한다. WorkLoop의 완료는 실험 산출/판정이 끝났다는 뜻이며 99% 성공이라는 뜻이 아니다.

## 미해결/재개 조건

한 장만으로 뒷면·정확한 깊이·조명과 재질을 유일하게 복원할 수 없다. 면의 일러스트 명암과 픽셀 배치가 기하에 종속되지 않는 원본은 동일 솔리드 모델로 정확히 맞지 않을 수 있다. 이 실행 결과 하나로 모든 NPR 기법이 불가능하다고 일반화하지 않는다. 추가 미술 보정은 이 시도의 결과를 보여 준 뒤 사용자의 새 요청이 있을 때만 한다.

## 실제 결과 — 99% 조건 미달

`LocalOnly/DeskReference20/`에 새 imagegen 기준, 정확한 `prompt.txt`, 목재/면색 재료, 실제 `desk.blend`, `render.png`, `render_coarse.png`, 추가 두 시점, 비교판을 보존했다.

| 검사 | 실제 관측 |
|---|---|
| 실루엣 IoU | 0.9557271901 |
| 전경 합집합 RGB 채널당 오차<=8 비율 | 0.5005544916 |
| 정확 RGB 비율 | 0.03110265173 |
| 교집합 RGB 평균 절대 오차 | 13.40528 / 255 |
| 99% 사전 수치 조건 | **false** |
| 공통 수식 vs Blender 투영 최대 오차 | 0.000372px |
| 4다리 | 모두 0.075×0.075×0.696019m, 발 Z=0, 상단 Z=상판 밑면 |
| 실체 | 부피 있는 메시12개, 광원0개, packed 재료 |

요청한 99% 재현의 성공이 아니다. 원본의 서랍/다리에 그려진 서로 다른 나뭇결과 국소색을 공통 목재로 대체한 차이, 단순한 면 경계/손잡이, 형상 추정 잔차가 남는다. 이 차이를 전부 원본 모순이나3D수학의 한계 탓으로 돌리지 않는다. **선택한 재료/형상 표현이 부족한 이번 실험의 실패**다.

첫 렌더 이후 독립 검토의 상판 crop/UV 역변환 누락을 수정하고, sRGB 곱색의 지수 근사를 재료 RGB 직접 곱셈으로 바꿔 한 번 재렌더했다. 같은 결과의 미술적 수치를 계속 조절한 반복은 아니다. 최초 Blender 저장본은 자동 백업 `desk.blend1`로 남아 있다.

초기 WorkLoop 최종 command 입력 키를 `artifact`로 잘못 작성해 프로세스 호출 전에 중단됐다. 기존 상태는 `LocalOnly/WorkLoop/desk-reference20/state.json`에 보존했다. 선언을 `stdin`으로 수정했고, 파일 검사 전용 `evidence.json`을 실행해 `desk-reference20-evidence/state.json`에서 exit0/graph_complete를 확인했다. 복구 중 생성/렌더를 반복하지 않았다. **graph_complete는 실험 증거 완비이며 99% 성공은 false다.**

재현: NumPy/Pillow Python으로 `prepare.py`, Blender5.2 background/factory-startup으로 `render_blender.py`, Python으로 `compare.py`와 `verify_result.py`. 생성 서비스를 다시 호출하지 않는다. 절대 경로와 측정치를 담은 한정 실험 도구로 범용 자동 복원 플러그인이 아니다. Unity통합·게임 내 캐시·임의 모델 모딩은 실행하지 않았다.
