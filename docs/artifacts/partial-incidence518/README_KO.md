## 표현과 비용의 책임

P는 기존511의 변형된 분절선 폐곡선 positive-winding 영역, M은514가 이미 선택한 공통480×272 격자입니다. 기존 유리수 교차점과 sweep face에서 I=P∩M, A=M\P(추가 채움), D=P\M(생략), 공통 경계를 기록했습니다. 양의 길이를 공유하는 face만 연결하며 점 접촉은 영역 통합으로 보지 않습니다. 새 mask·근접 반경·계수·영역 선택은 없습니다.

픽셀 unit edge를 P 경계와의 실제 교차점에서 분할하여 A/D/공통 부분과 selected-region owner를 보유합니다. 원래 문제였던(209,52) outgoing edge는 D부분 뒤 A부분이므로 edge 전체를 한 원곡선에 강제 귀속하지 않습니다. corner 연결은 끝부분 incidence를, 기존 편집 비용용 anchor는 중심부분 incidence를 사용합니다. 각 unit의 정확 길이 합은1이며 편집 비용 표본도1개입니다. 분할 수가 늘었다고 add/delete 비용이 증가하지 않습니다.516의 add/delete/substitute/merge/split 및 시간 상태·장벽·계수는 수정하지 않았습니다.

phase0의614개 sweep 조각을 동일 incidence별로 합쳐204부분(72개 split edge, 최대4부분/edge)으로 보유했습니다. 부동소수점으로 직렬화한 교차점에서 정확 공선성 검사가 잘못 거부하는 경우는 기존 exact overlay의 동일 활성 폐곡선을 유일하게 대응시켜 원 유리수 선분으로 검사했습니다. geometry/cost float 배열은 그대로이며 새 근접 반경으로 연결하지 않았습니다.

## 첫 잔여 실패와 중복 제약

영역 선택이 통합/생략한 오목부에서는 부분 경계의 방향과 unit 전체 방향이 같을 필요가 없습니다. 기존 unit 단위 방향·양끝 거리 제한은 이미 증명된 영역 incidence에 추가한 표현 제약입니다. 그렇지만 **그 제한만 삭제하는 것도 충분하지 않습니다**. 반례에서 하나의 연결된 A ribbon은 사각형 둘레 전체에 닿아 top pixel edge가 반대편 bottom 원곡선도 후보로 받습니다. 실제 최종 경로가 잘못 선택됐다는 주장은 아니며, 무제약 후보 유입만 증명했습니다. 별도 disconnected source 영역은 incidence에서 거부됐습니다.

최소 다음 의존성은 동일 선택 영역의 **순서 있는 국소 경계 chain과 정확 부분 전이**를 대응 표현이 사용하는 것입니다. 전역 A/D component 공유만으로 먼 반대쪽 경계를 대응시키거나, unit 전체의 한 tangent로 다시 제한해서는 안 됩니다. 이번에는 새 규칙/필터 삭제/문턱 확대를 구현하지 않았습니다.
