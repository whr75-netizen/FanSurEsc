## 수정한 책임

KEEP 틈을 별도의 `SelectRegions543(holeAreas, …)`로 다시 선택하던 경로를 제거했습니다. 이미 선택한 signed 양의 형상 `P`와 원본 틈 교차면적에서 `!P && clippedArea > 0`인 음의 셀을 같은 권위로 결정합니다. 연속 원본의 `sourceOpen`과 격자 선택의 `referenceOpen`은 별도 사실로 남깁니다. FILL 폭 2 논리픽셀, 외부 envelope, 양의 형상 보호·계수·이력은 바꾸지 않았습니다.

`HeadCurve511.cs`의 명시적 준비 입력 adapter는 원래 리소스 기본값을 유지합니다. yaw260의 자동 전처리 입력은 2폐곡선/114제어점이고 준비비용 10.662초입니다. 프레임 비용이나 자동 모든 방향 지원으로 해석하지 않습니다.

이번 후속 작업에서 렌더 소스는 변경하지 않았습니다. `CanvasView576.cs`만 원본 전체 화면을 저장하도록 바꿨고, 분석기의 머리 ROI 위치도 실제 캔버스/메타 좌표로 환산하게 고쳤습니다.

## 비용과 운영 상태

42완료쌍 ON의 캡처 중 내부 CPU 중앙값은 Build 225.07ms / packet 182.35ms / area 16.67ms / curve 0.033ms입니다. P95는 각각 270.52 / 214.34 / 34.07 / 0.046ms입니다. 캡처 readback·파일 저장은 이 내부 계측창 밖에서 실행됩니다. 진단 실행 조건의 내부 시간이며 Player FPS/GPU 수치나 최적화 성과가 아닙니다. 새 할당량 측정은 하지 않았습니다. 실시간 성능 채택은 보류합니다.
