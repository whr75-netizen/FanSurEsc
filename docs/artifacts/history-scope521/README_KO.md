## 독립 분리의 조건과 실제 결과

독립 성분으로 두려면 공유 pixel/owner 변수가 없고, 현재 면적·포함·8이웃 비용과 시간 편집 정렬 factor가 분할을 가로지르지 않아야 합니다. 공유 변수가 있으면 그 조건부 separator 메시지를 남긴 채 변경 성분만 주변화해야 합니다. source arc ID가 다르거나 screen상의 셀이 떨어져 있다는 사실만으로 독립으로 보지 않습니다.

실제 정지 반례의12셀은 서로8이웃이 아니지만 모두 같은 canonical outer arc0의 편집 DP에 들어갑니다. (229,35)는 arc0과 hole arc2에 함께 걸립니다. 검증된 raw36은 outer34+hole2이며 outer span71→72, hole2→4입니다. 따라서 셀별 이력값 또는 arc별 독립 이력값을 그대로 더하는 방식은 현재 비용 인터페이스와 같다고 증명되지 않았습니다.

## 현재 구현의 비용

현재 `span517.compare`는 완성된 두 drawing의 대응/전체 cyclic span 편집을 계산합니다. outer71×72 span에서 회전72번을 시도하며 각 회전의DP표는72×73입니다. 최종trace 전만378,432개DP cell을 방문하고 merge/split과 cyclic경계가 포함됩니다. 현재 API는 scalar와 최적trace를 반환하며, 성분을 나눌 때 필요한 입구/출구 정렬 조건별 메시지는 반환하지 않습니다.

동일 frozen기하의 두 실제 drawing에 대해, 범위 계산이 끝난 뒤 별도6회 측정한 compare 호출만 **중앙값0.945초, 범위0.934~0.960초**였습니다. overlay/후보mask구성/Unity시간을 포함하지 않습니다. 첫 병렬측정은 참고 파일로만 보존했습니다. 이는 현재Python 호출의 실제 비용이며 실제 애니메이션 FPS·배포구현 하한이나 관리할당 측정이 아닙니다.
