생활잡화점 01

맵·건물 설계 → 사물 배치 → 투영 가이드 → 생성 원본 → PerfectPixel 공통 격자

현재 범위: 1층 전체 공간의 정지 아트입니다. 중앙 인물은 비율용 임시 표식입니다. 개별 가구 스프라이트·동적 가림/조명·Unity 통합은 아직 하지 않았습니다.
정규화: 기존 수정 PerfectPixel의 source_regions 샘플링만 사용했습니다. 새 색상 혼합·전역 팔레트 제한·명암 추가·선 재작성은 껐습니다. 작은 무늬가 줄어들 수 있으며 방향·설계 일치를 자동 보장하지 않습니다.
그림과 설계의 차이: 생성 모델이 계단/문·가구의 세부와 장식 배치를 해석했습니다. 도면과 픽셀 이미지가 기하학적으로 완전히 일치한다는 판정은 하지 않았습니다. 최종 게임용 분리는 설계 데이터를 원본으로 유지해야 합니다.
