## 분리한 두 실패 원인

### A. 대응 구현이 기하 재매개화에 불변하지 않음

동일한 직사각 폐영역·동일한 mask·동일한 제어점 수/순서에서, 직선 위의 중간 제어점만 옆으로 미는 반례를 만들었습니다. 영역과 그림은 바뀌지 않지만 현재 비용은5.5입니다(두 source channel의substitute3.0+2.5). 고정 `(ring,segment)`별 분할과 material parameter에 결박한 이동이 실제 실루엣의 기하 대응을 대신한 탓입니다. 정수이동/90도회전 cost0을 통과했다는 사실이 이 반례를 덮지 못합니다.

저장81입력의 변하지 않은 grid edge 중192회는 source segment 채널이 바뀌고,165회는 현재도 활성인 인접 source segment 사이입니다. 전부 실제 오류로 확정하지는 않았습니다. 움직이는 연속형태의 다른 가지가 같은 셀을 지원할 수도 있습니다. 정확한 재매개화 반례가 구현 불변조건 실패의 근거입니다.

**진단 라벨 정정:** 기존 audit의119개 `NO_CURRENT_VISIBLE_SPAN`은 해당 source channel에서 선택된 픽셀 span이 없어졌다는 뜻이며, 실제119번 가림이 아닙니다. 이 부재를 물리 가림으로 보고 이력을 해제하면 안 됩니다. 비용 구현은 별도 common-active-interval을 사용하지만, 진단 라벨을 실제가림증거로 승격하지 않았습니다.

### B. 한 단계 전환 비용이 정지 기하에서도 과거 모양을 붙잡음

기준계수 끝점의12셀 차이를 현재 기하 그대로 고정하고 비용만 평가했습니다. 후보유지 시간비용0, 정적선택복귀 raw편집42/가중5.88입니다. 복귀는 공간 비용2.042562를 개선하지만 한프레임 목적은오히려3.837438 나빠집니다. 허용된142개 모든1셀변경을 평가해도 최소증가+.015435였고, 정적선택방향12개변경도모두불리합니다. 반복프레임을다시풀거나루프를재촬영하지않고, 현재 선택기가 정지 입력에서 local fixed point가 되는 근거를 확인했습니다.

이는 정적 cut이 미관의 정답이라는 주장이 아닙니다. **지속되는 현재 기하의 더 좋은 형태 근거가 누적되지 않고 매프레임 같은 전환 장벽을 다시 내는 구조**라는 뜻입니다. 단순 warm-up 미실행으로만12셀 차이를 넘기거나 새 계수로 감추지 않습니다. 실제 steady loop의 주기성을 추가 측정하지 않았으므로 그것까지 실패/통과로 단정하지 않습니다.
