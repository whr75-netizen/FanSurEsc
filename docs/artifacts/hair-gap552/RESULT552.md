# 552 헤어의 음의 영역 출몰: 기존 경로 재사용 판정

2026-10-23. 몸·손551과 독립된 검사다. 제품 헤어 코드를 새로 수정하지 않았고 기존511/513 경로를 재사용했다. 기본OFF/미채택이며 전체 헤어 양자화 완료가 아니다.

## 현재 사례와 최초 단계

550 수정본 전체81포즈의 head-local 좌표를 맞춰, 앞뒤 프레임은 머리인데 가운데 한 셀의 틈이 나타나는 표본7개를 찾았다. 이는 오류7개라는 뜻이 아니다. 35번 head-cell(226,54), main-cell(223,55)은 상하좌우가 머리인 한 셀 얼굴 영역이다. 34/36은 머리 source14, 35는 얼굴 source4이며 Prepare/Join 이전 source 래스터부터 바뀐다. 550의 잘못된 몸 가림 사례와 다른 원인이다. 511/491은 이 기준본에서 OFF이므로 현재 사용자 화면에는 그 폐영역 양자화가 적용되지 않는다.

기존514 자료의 같은 좌표/포즈 source owner 및 primitive가 현재550 표본과 일치한다. 기존514의 폐곡선 입력 면적은34/35/36에서0.98209119/0.98095632/0.97990191셀이고, 선택 마스크는 세 포즈 모두hair=true다. 원시 중심점은 작은 음의 영역을 만나 얼굴로 바뀌지만, 기존 곡선으로 설계한 대부분 머리인 셀은 연속된 양의 영역으로 채운다. 이 수치는 기존514 저장 계산이며 이번 새 면적 계측이라고 표시하지 않는다. 기존514와 현재는 조명 시간이 달라 RGB 대조로 사용하지 않았다.

## 현재 프로젝트 실제 검증

## 결론과 다음 의존성

이 한 셀 틈에는 기존 폐영역 경로가 이미 유효하다. 새 closing/dilation/픽셀삭제/시간필터를 덧붙일 근거가 없다. 현재 source 중심점 경로와 기존 영역 경로의 ON/OFF 차이를 실제로 확인했다. 다만 기존 선택기는 면적+경계 비용의 공간 선택이며 모든 음의 영역에 지속 ID/폭 정책을 명시한 구현은 아니다. 이 국소 결과만으로 모든 한 줄 틈의 영역화 요구를 충족했다고 판정하지 않는다.

다음에는 기존514에 보존된 선택 반전에서 음의 연결 영역과 경계 선택의 관계를 확인하고, 별도로 packet 합산 구간의 실제 상위 비용을 분리해야 한다. 전역 시간DP/상태뱅크/무조건 틈 채움은 재개하지 않는다. 이미35를 처리하는 경로를 다시 구현하지 않는다.
