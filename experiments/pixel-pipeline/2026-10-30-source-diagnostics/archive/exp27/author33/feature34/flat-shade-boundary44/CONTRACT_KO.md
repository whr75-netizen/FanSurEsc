# 단색 명암 영역의 공유 경계 보정

요청: 단색에서도 남는 Q의 11영역/6단독 셀 원인을 좌표와 source로 분리하고, 영역 형상 보정 결과를 출력한다. 대상은 같은 frame95의 368개 가시 hair 셀이다. 원래 Q(g), g, source packet, geometry, 마스크, 팔레트는 고정한다. 후속 공간 라벨 Q'를 별도로 만든다. 제품·Unity·31·34·Desktop·기존 결과는 변경하지 않는다.

## 현재 시험의 연산

`고정 source/g → 기존 임계값 count(g≥τ)=Q → 두 라벨이 공동 사용한 경계 → 실제 가림/마스크/접합점 고정 → 연속 구간 cubic 근사 → 셀 중심의 양쪽 영역 membership 재계산 → Q' → 같은 P[Q'] 직접 채움`

2D 논리32×40 셀 좌표, x 오른쪽/y 아래쪽, 정수는 셀 모서리, 중심은 (x+.5,y+.5)다. 표시 크기는 2×, 추가 확대는 nearest다. 색·g의 평균/블러는 없다. 두 영역의 같은 경계를 반대 방향으로 공동 사용하므로 각 영역을 따로 팽창/침식하지 않는다.

그리드가 만든 90도 계단을 전부 실제 코너로 보호하지 않는다. 근사 오차 허용은 논리 셀 중심에서 모서리까지 거리 sqrt(.5)=약 .7071셀을 해당 입력 격자의 공간 근사 상한으로 쓴다. 미술 최적값이라는 주장은 아니다. 이것은 source guide와 새 격자 근사의 거리이며 원래 들쭉날쭉한 모든 계단 꼭짓점이 정답이라는 제약으로 쓰지 않는다. 실제 hair-vs-hair 가림/투영 빈틈을 넘어 g를 보간하지 않고 owner/depth/마스크는 고정한다. 그 경계에 닿았다는 이유만으로 셀의 명암 보정을 전부 막지는 않는다. 마스크 끝점·다중 라벨 접합은 고정한다. 실제 가림은 기존 평가 정점으로 **현재 선택 packet의 실제 투영점**을 검사하고, 과거 셀 중심 기준 edge 분류를 그대로 재사용하지 않는다.

새 경계로 셀 라벨을 바꿀 때는 원래 두 이웃 라벨 중 하나만 사용하고, 바뀐 셀·기존g/Q·새Q'·명암 오차·source 지원·경계 이동을 모두 기록한다. 다른 domain/실루엣/alpha는 보존한다. 모든 원래 Q섬을 정답 topology로 동결하지 않되 작은 영역을 면적만으로 없애지도 않는다. source 지지가 있는 얇은 명암 영역의 보존 여부를 별도로 판정한다.

source 지지 표본은 기존 셀 내부로만 제한하지 않는다. 후속 경계가 움직일 수 있는 같은 공간 오차 범위(셀 바깥 거리 sqrt(.5) 이하)에서 현재 선택 표면과 같은 chart의 실제 native Q 표본을 찾고, 두 실제 점 사이에 가림/빈틈이 없는지 검사한다. 팔레트나 다른 표면의 RGB를 가져오는 방식이 아니다. 원래 coarse 셀 칸을 절대 영역으로 보호하면 공간 보정을 무효화하므로 그 제약을 제거한 것이다. `.7071`은 입력 격자의 근사 범위이며 미술적으로 최적이라고 승인받은 수치는 아니다.

## 검증 기준

고정 source ID/packet SHA와 실제 단색 분기를 재현하고, Q→Q'·공유곡선·RGB를 각각 비교한다. 공통 경계 수정 뒤 각 셀의 영역 membership이 정확히 하나여야 하며 틈/겹침은 실패다. 색간격 변경은 RGB만 바꾸고 Q/Q'/곡선을 바꾸면 안 된다. 순회 순서로 달라지면 실패다. 최소 둘레/단독 수 감소만으로 성공 판정하지 않고 원래 크기와 확대에서 곡선 진행·보존한 반례를 검수한다. 실제 연속 움직임은 미검증이다.
