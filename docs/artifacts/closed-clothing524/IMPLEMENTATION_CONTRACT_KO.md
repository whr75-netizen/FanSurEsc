# 524 수정 전 계약

## 입력과 경계 결정

현재 변형 body renderer0의 선언된 clothing material/submesh3(2093삼각형)만 입력한다. 다른 모델의 의상 의미를 임의 추론하지 않으며 adapter 불일치는 unsupported다. 피부 손가락/팔/다리와 얼굴/눈/머리는 별도 원래 경로다.

투영 삼각형의 방향을 통일하고 공유 유향변을 상쇄한다. 남은 가중 변을 실제 교차점에서 분할하고 양쪽 positive-winding을 비교하여 연속 합집합의 닫힌 경계를 얻는다. 기존 compile_curve511.vector_union의 같은 절차를 런타임 double로 옮긴다. 좌표1e-8셀 정규화와 그에 따른2e-8셀 선 위 수치 허용은 연산 동일점 식별용이며 형태 허용치가 아니다. 원본 중심표본/alpha 마스크, ROI 박스, 볼록껍질을 경계로 쓰지 않는다.

닫힌 원곡선은 기존 .1875논리셀 RDP 오차 안에서 선분 곡선으로 표현한다. Bezier/의미 자동 저작이라고 부르지 않는다. CurveArea511로 곡선과 각 셀의 교차 면적 A를 계산하고 기존 SelectRegions의 E=sum(z?(1-A):A)+.14*8방향 경계 길이 비용을 한 번 사용한다. 시간 DP/이력/후단 morphology를 연결하지 않는다. 최종 선택 셀들의 닫힌 격자 경계가 C이며 내부 채움의 유일한 허용 영역이다. 공간 비용만으로 전체 시간 품질을 보장하지 않으며 실제 Walk로 판정한다.

저장된33/34/35의(198,85) 곡선 면적은 .41389364/.44287090/.42408735이고 선택은 모두false다. 현재 centre hit 0/1/0을 복사하지 않는다. 대표 셀/위상 좌표를 제품 코드에 넣지 않는다. 기존 상수는 계수 맞추기로 바꾸지 않는다.

## 채움·소유권

원본 소스 Probe의 옷 fragment를 C 밖에서 discard한다. 그러므로 원래 depth test가 뒤 피부/파츠를 드러내며, 나중에 RGB만 지우는 방법이 아니다. C 안의 기존 중심 패킷은 색/UV/depth를 그대로 사용한다. C가 선택했지만 중심 ray가 비어 있는 셀만 그 셀의 실제 native2×2 중 가시 옷 패킷을 받아 채운다. 중심에 이미 다른 파츠가 있으면 덮어쓰지 않는다. 같은role를 같은surface로 간주하지 않고 primitive/UV/depth가 함께 이동한다. donor가 없으면 명시적 audit 실패다.

Prepare와 최종Resolve가 같은 C를 사용한다. 최종 게이트 위반은 별도 audit으로 남겨, 지워서0이 된 결과를 성공으로 숨기지 않는다. 후보가 켜지면 기존 part2 한 팔의 열린 ±1셀 선택을 대체한다. source→닫힌 디자인 영역→채움/outline→최종 합성의 책임이며 head511 위에 덧씌우지 않는다.

## 범위와 판정

기본OFF. 세 실제 인접 포즈에서 C 선택/패킷/실제 가림/소매 끝/피부 손가락을 먼저 확인한다. 통과 후 전체 실제 Walk 한 루프의 모든 프레임과 정상속도 전신 비교를 보존한다. 경계 밖 쓰기, 경계 자체 출몰, 내부 명암, 가림을 구분한다. geometry/area/selection/upload 및 전체 렌더 시간을 분리하고 느리면 미채택이다. 실험 후 초기 Edit/입력/Animator/시계/후크를 복원한다.
